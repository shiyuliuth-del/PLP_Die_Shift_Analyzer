# V69 使用说明

## 层叠设置

- 单击「用途」展开选项。单击「补偿」数值后可直接输入或拖选文字。需要换行时，在「层 / 类型」列拖动。
- 把用途改为运动 RDL 或固定 RDL 时，补偿自动设为 +1.500 μm。切换到其他用途时设为 0.000 μm。随后仍可手动改值。重开工程沿用已保存的补偿，旧工程已有的默认零值也保留。
- 「运行信息」采用本地时间，格式为 `YYYY-MM-DD HH:mm:ss`。

## 一并导出

将辅助图层的用途设为「一并导出」。该层保持名义位置，不参与偏移、连通、DRC 或重构。显示仍由层叠表控制。

「动静区输出」将这一层作为标准 DXF 图层附到同一文件。它使用自己的原层号和数据类型，应用逐层补偿，并遵循普通 DXF 的比例、合并、实体及孔洞设置。即使预览中隐藏，该层也会输出。固定 RDL 的 ABC 轮廓仍按自己的分区规则写出。

实测单姿态 GDS 和批量 OAS 均包含这些图层。软件在实测工程准备时计算一次补偿，同一批次的所有姿态复用补偿后的静态图形。
