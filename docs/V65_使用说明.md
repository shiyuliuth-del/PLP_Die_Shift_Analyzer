# V65 使用说明

## 忽略阈值

「连接与工程」中的「忽略阈值」后面是无文字复选框，默认不勾选。勾选后才可输入 X、Y（μm）和旋转（°），均保留三位小数。关闭仍保存已填数值，计算时停用过滤。启用后，封装内所有 DIE 的三项绝对值均严格小于对应值才引用共享的名义封装 Cell。

旧项目首次用本版打开时，复选框默认关闭。已保存的旧计划继续沿用创建时的阈值。

## 实测进度与实时命令

进度条只显示已完成数和总数。普通运行按封装计数，计划运行按计划任务计数。自动补算保留已达到的进度，输出校验及保存完成后进度条才填满。鼠标悬停可查看开始时间、结束时间与耗时。批次详情与故障原因在任务日志中。

打开「实时命令信息」标签页时，界面接收并显示实时命令。切走页面后停止排队和刷新显示，这期间的消息仍写入项目的 `logs/IPC-conversation.log`。

主程序用法参见 [V64 使用说明](V64_使用说明.md)。两个应用仍共用根目录的 `BUILD.bat` 与独立启动脚本。
