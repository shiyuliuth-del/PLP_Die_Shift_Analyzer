# Die Shift Analyze V80

## Windows 授权

Windows 新机器码由电脑 UUID 和本机网卡 IPv4 生成。复制激活窗口的一行 Machine ID 交给管理员。管理员使用 V80 签发工具，保持机器码版本为默认 V2。已签发的 V79 逐机许可继续根据旧版绑定校验。已签名的通用许可证可以继续使用。局域网有有效 IPv4 即可离线授权。原绑定的 IPv4 从本机消失后，使用新 Machine ID 重新签发逐机许可证。

## 签发和构建

从 GitHub Release 下载源码 ZIP，在解压后的根目录执行 `BUILD.bat --admin-only`，然后双击 `dist_admin/LicenseManager.exe`。首次部署点击「生成密钥对」，在用户端源码的 `BUILD.bat` 同级放置管理员导出的 `public_key.pem`，或设置 `DIE_SHIFT_LICENSE_PUBLIC_KEY` 指向它。已有正式公钥时直接沿用。仅需构建签发工具时使用 `BUILD.bat --admin-only`。

完整构建开始先校验正式公钥。在安装版 KLayout 后端的预检查中，程序先结束自己的 KLayout 进程，再清理临时日志。
