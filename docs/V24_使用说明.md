# Die Shift Analyze V24 · PATH、图形节点与相邻孔盘

## 读取图纸

有宽度的单点 GDS PATH 会导入为圆形。圆心取展开到顶层 Cell 后的实际坐标，直径取 PATH 的实际宽度，几何用四个方向均带顶点的圆形多边形表示。重复记录同一坐标也按单点处理。阵列、镜像、旋转和倍率参与展开。负 WIDTH 表示绝对宽度，实例放大时其直径保持不变。零宽 PATH 在导入前按图层统计并忽略，勾选右上角“运行信息”可查看带时间戳的警告。命令行打开工程时也会输出警告。[gdstk PATH 说明](https://heitzmann.github.io/gdstk/gettingstarted.html)

## Q 查看和编辑

1. 在“结果图形”中左键单选或框选，按 **Q** 打开属性窗口。类别菜单按用途、GDS 层和图形类型汇总图形数与节点数。图形菜单可逐个切换。
2. “名义节点”显示顶层坐标，单位为 μm。多边形编辑轮廓节点，PATH 编辑中心线，单点圆显示一个圆心和实际直径。“当前预览轮廓”可以分别查看实际显示的外轮廓和内孔。一个预演图形涉及多个源图形时，窗口会列出这些源图形。
3. 双击坐标可以改值，用“插入节点”“删除节点”调整轮廓。可跨多个图形暂存编辑，最后点击“应用”。错误会指明图层和编号，整批编辑需全部有效才会应用。“恢复源坐标”只恢复当前图形，“取消”放弃本次待应用的修改。
4. 编辑作用于所选顶层展开实例。应用后图形、网络、归属和数值缓存按新几何重建，已有评估会重新计算。点击“保存工程”可保留编辑，源 GDS 的文件内容和其他阵列实例保持原样。旧工程缺少这些字段时使用原 GDS。[KLayout 选中对象属性](https://klayout.de/doc/manual/selecting.html)

## 分清计算和显示

左侧图层复选框控制画布显隐。参与范围来自“用途”和层叠顺序。隐藏图层后，方案结果、宽度表、边距违规、位移统计及 Space Map 数值仍使用完整参与层。派生标记会跟随对应源图层隐藏。若需改变实际参与范围，请修改图层用途。

“设置 → 宽度分析 · 元素显示”可分别选择**显示、低亮、隐藏**。选项包括运动和固定 RDL、过孔实体、边框、孔盘、固定障碍、通道矩形、风险描边、文字箭头和边距标记。进入宽度分析后，原始 RDL 默认低亮，仍可在画布上选择。“显示宽度足够”保留为单独的绿色结果筛选开关。这些显示偏好随工程保存，切换时直接重绘。

## 视图操作与回到无偏移

普通模式中，右键单击把点击点移至视图中心，缩放比例保持不变。按住右键向任意方向拖框并松开，视图会按窗口宽高比完整容纳选框。滚轮仍可缩放，中键仍可平移。在 M 模式下右键拖动所选芯片，Ctrl + 滚轮缩放。按 Esc 退出 M 模式后即可使用右键视图导航。

“设置 → 视图与预演运动”中的“返回无偏移时播放渐变”默认开启，并与主渐变开关配合。选中极端表第一行或把手动偏移调为零时，保留当前画面，播放至准确零位；中间帧和零位终态可按几何、工艺、起止姿态及采样步数复用。相同条件下反向切换也可复用已经过校验的中间帧。关闭返回开关仅令返回直接显示零位。显示偏好随工程保存。

## 相邻孔盘和封装边距

一个矩形截面只评估两个相邻实体壁之间的开口。运动孔和孔盘跟随所属 DIE 平移、旋转，尺寸固定。孔盘至少包含过孔实体和最小包围量。可识别的独立同心落盘或与走线连成一体、仍有明确圆弧或四边证据的孔盘会保留其较大尺寸。只连固定过孔的金属网络整块作为固定障碍。

若第三孔盘进入评估矩形，即使只碰到矩形的一侧，也按**完整孔盘在通道方向的投影**预留空间。分析将开口拆成相邻区间。落在孔盘上的载线按刚性实体占用，只有不在该孔盘位置的线路才允许按工艺最小线宽收窄。各区间保留原有穿越次序和需求，材料归属按几何连通推定。

设 $j$ 是一个相邻区间，$g_{0,j}$、$g_{t,j}$ 分别是名义和当前姿态下两实体壁之间的净宽。对与矩形相交的刚性孔盘 $P$，令 $(x,y)$ 表示其顶层坐标，$\hat d$ 为截面纵向单位向量。沿该方向的保留宽度为

$$
b_P=\max_{p\in P}(p\cdot\hat d)-\min_{p\in P}(p\cdot\hat d).
$$

$p$ 遍历孔盘轮廓顶点。$w=w_0-\tau$、$s=s_0-\tau$ 是工艺固定线宽、线距减去共用 DRC 容差。最小包围量直接取工艺值。$N_j$ 是区间内必须穿越的自由线路数。若某条线在名义截面上的铜交段中点为 $m_i$，其铜轮廓为 $R_i$，局部原宽 $u_i=2\operatorname{dist}(m_i,\partial R_i)$。直线斜穿时该量仍沿线路横向测量。区间单独计算

$$
C(g)=\max\left(0,\left\lfloor\frac{g-s}{w+s}\right\rfloor\right),\quad
W_{\rm keep}=\sum_{i=1}^{N_j}\max(u_i,w)+(N_j+1)s,\quad
W_{\min}=N_j w+(N_j+1)s.
$$

箭头依次给出原可通 $C(g_{0,j})$、必须通过 $N_j$、现可通 $C(g_{t,j})$。保持原宽可通过为绿色，收窄后才可通过为琥珀色，低于最小需求为红色。$N_j=0$ 时，两块异网刚性金属或金属与封装边框之间仍须满足一道线距。位于同一对孔盘不同位置的截面可分别列出。

风险矩形画在线路边缘上方。琥珀和红色风险使用相应色系的深色半透明描边；只有线路实体与本行矩形相交的部分带半透明斜纹。箭头第一行的原宽、必过和现宽均以根计，第二行显示该处所有自由线路合计需要减少的宽度。例：

```text
原宽:3,必过:3,现宽:3
预期收窄:3微米
```

有自由线路时，$\Delta W_j=\max(0,W_{\rm keep}-g_{t,j})$。没有自由线路时该值为零，刚性孔盘的净距仍独立判定。例如保宽要 105 μm，当前开口 90 μm，则预期收窄 15 μm。红色截面表示收窄到工艺下限也无法通过。

线路到封装边框还要独立检查实际铜图形。令 $B$ 为封装有效区域，包含外缘和内孔，$s_k$ 为当前线路层的有效线距，$D_{s_k}$ 为半径 $s_k$ 的圆盘。当前铜 $R$ 的违规区域为

$$
E=R\setminus (B\ominus D_{s_k}).
$$

恰好达到线距算通过，越出封装或进入内孔按零净距报告。窗口会标记实际违规铜，报告给出层、图形编号、实测距离、要求和位置。局部通道容量与整条线的实际边距是两项独立结果。

## 复算示例

打开 **示例P_单点PATH与相邻孔盘**。4/0 的五个直径 16 μm 的单点圆均可用 Q 查看。77/0 只有零宽 PATH，运行信息应列出一条警告。中间孔盘虽不穿过外侧两孔的中心连线，但进入矩形时会保留整个孔盘。左边界附近的一块 5/0 铜距边框 5 μm，工艺要求 15 μm，实际违规区域应可见。

```bash
python3 -m unittest tests.test_v24 -v
QT_QPA_PLATFORM=offscreen python3 tests/gui_v24.py
python3 tools/validate_width_v24.py --gds /path/to/GD55_9-21.gds
```

真实 GD55 的名义姿态与八种 ±35 μm、±1° 同向组合都可用上述命令复算。脚本独立检查每个正宽矩形，验证内部没有未列为端点的第三个实体。数量是局部截面数。完整布线可行性及量产良率需分别评价。[数值验证记录](../results/width_V24.json)
