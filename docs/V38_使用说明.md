# V38 共用动区与动静区输出

本版从已合并全部远端来源的 main `a82099e` 开始；不恢复旧分支的单刀算法。“预演分析”及专属搜索、进程池和界面已删除。“重构预演”“修复补块”仍是独立功能。

## 操作

1. 导入 GDS，手动指定层用途、上下面顺序与芯片/封装边框。设置固定、运动 RDL 的线宽、线距和各自包围量。
2. 完成方案评估，启用“重构预演”。自动沿原铜内部追溯，优先选取可切分的长直段；每颗 DIE 的全部离散极端参与候选检查，且使用完整输入位移包络作为过渡余量。名义端点只确定一次，各姿态共用。
3. 拖动蓝色运动侧边界或玫红固定侧边界，另一端保持原位。沿追溯方向可跨拐角，拐角内会吸附到预留范围之外。两端不能相互越过。近端退到整个运动孔盘以内时，蓝线变为较大的蓝点；从蓝点反向拖动可恢复线边界。
4. 设置→重构预演的“实时反馈动区变化”默认开启。拖动时边界脉动高亮，局部动区即时更新；松开后刷新完整预演及最终异网间距。关闭时仍能拖动高亮边界，松开后更新铜形。完整检查尚未完成时不应把局部拖动画面当作DRC结论。
5. 双击端点恢复该端自动位置；“清除全部手动切口”恢复所有自动端点。手动端点、开关与工艺参数均保存到工程。

## 三种区域与 DXF

- **A 动区**：两端之间改变形状、过渡连接的原始铜。
- **B 静区**：固定连接端，位置不动。
- **C 平移区**：运动连接端，随所属 DIE 做完整刚体变换（包含旋转）。

输出页的“动静区输出”紧接“DXF输出”。先完成重构预演，再选择系统保存框中的文件位置。该输出会按当前姿态和最新工程端点重新冻结区域；固定 RDL 原层名后加 A/B/C，例如 `L5_D0A`、`L5_D0B`、`L5_D0C`。其他层保持原层名。

只导出最终实体的外轮廓与孔洞轮廓。内部区域切面不输出；各类折线在相同接口端点断开，各层叠加才还原完整闭合图形。不输出HATCH、不恢复圆弧。完全位于某一类中的独立闭合轮廓保留首尾坐标，DXF仍采用开放折线实体。

两个按钮共用“DXF”参数中的图层范围、Merge、孔洞拆层与输出比例。普通 DXF 的实体/HATCH偏好不改变“动静区输出”只输出轮廓的规则。文件先写临时文件并回读校验，失败不覆盖旧目标。输出不修改源GDS。

## 精简设置与兼容

“极端足迹”是唯一开关：半透明热图表示完整过孔实体覆盖概率，浅色虚线表示离散极端实体足迹；其颜色与数值算法在同一栏目。∞仅显示当前实体的0/100%覆盖，不生成离散全域概率云。

缓存参数与清除按钮位于“硬件与计算资源”。接触位置标记默认关闭，已证明满足良率门限的低概率位置也默认隐藏；可在设置中开启低亮显示，未定概率不会冒充低概率。

工程仍为 schema 5。旧 `annulus_um` 保留为固定RDL包围量，新 `moving_annulus_um` 缺失时继承旧包围量。旧概率/足迹开关按“任一开启”迁移为新开关，旧预演分析开关不能重新启用删除的功能。旧切线投影到原图追溯路径；保存新的弧长端点和路径指纹。源节点或用途改变后，失配路径不会盲目套用旧端点。

## 计算边界

自动选择是有预算的几何候选搜索，不是任意拓扑的全局最优布线证明。独立DIE候选检查不能代替全部跨DIE耦合的最终DRC；最后按整张当前几何重新测量异网净距。紫色轮廓及表格说明表示空间、拓扑或折叠约束无法满足；未通过几何合法性时保留原图，不生成错误铜形。

过渡用原始材料连续移动，不在移动过孔下方另补一块孔盘冒充重构。铜边界按源DBU量化；仅允许在DBU范围内修复接缝细片。默认与各极端共用定义，回零、切换、动画复用缓存。

正式发布仅含运行源码、RUN.bat、BUILD.bat、依赖清单及构建规范；不含图片、GDS、EXE。Windows离线环境与实际CUDA设备需分别验收，Linux测试不代表目标电脑通过。
