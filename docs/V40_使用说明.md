# V40：重构状态、边界角度与可复用检查

本版基于 V39 主线 `04093da99640c5513b2bd15db57abc7b614853de`。长度统一为 μm，界面角度为度，几何计算使用弧度。原 GDS 只读，所有操作保存在工程中。

## 动区颜色和问题详情

重构预演直接检查最终固定 RDL 的线宽、线距、连接过孔包围量、封装边距、禁布区和连接结果，不依赖“DRC问题”显示开关。

| 当前动区状态 | 填充 |
|---|---|
| 当前姿态违规，且没有低概率证明 | 浅红 |
| 当前姿态通过，但其他离散极端违规 | 浅黄 |
| 全部离散极端通过 | 浅绿 |
| 当前姿态违规，但连续失效概率上界已满足良率要求 | 浅灰 |
| 全部极端尚未检查完或无可信分区 | 保留警示，不能冒称绿色 |

红色只填 **A 动区**；实际违规几何另用粉色区域和小圆圈定位，可能位于它连接的 B/C 区。原图自身的规则问题也会计入。无偏移首行汇总全部离散状态，等级为 **红 > 黄 > 绿 > 灰**。因此某动区只有低概率失败、但另有通过姿态时，首行仍按黄色显示。首行的真实违规位置可来自不同极端，它们不是当前零姿态发生的全部违规。

左键选择问题源图形，在画布内显示与宽度分析一致的白底文字、箭头和框线；Shift/Ctrl 多选/扣除、空白和 ESC 取消沿用原选择逻辑。包含规则原因、工艺阈值、边界角度、概率证据和代表偏移。视野外箭头定位最近画布边缘。蓝黄拖动柄仍独立拖动；不会把点击动区变成拖动柄。

开启重构预演后，“过滤无问题情况”依据 **实际重构规则失效**，不再用原图过孔接触代替。直线、一阶、二阶、圆弧使用同一规则入口。灰色只改变风险解释，不从几何违规筛选中删掉；空白首行始终保留。

## 边界角度

设置 → 重构预演 → **边界角度**：

| 选项 | 行为 |
|---|---|
| 垂直（默认） | 沿用原图追溯路径的垂直截面 |
| 重构区优先 | 在规则优先的前提下，比较实际动区两侧的净宽，选择较宽的候选 |
| 两侧平均 | 同时比较两端、两条侧边及截面两边的角度，优先提高最小夹角，再提高平均夹角 |

位置仍由原图共用的两个弧长端点决定，所有极端双向对应。新选项只使截面方向随姿态调整，不交换端点，也不改变用户选中的连接样式。整孔盘模式保留实体，角度检查使用孔盘外的真实连接截面。

候选由原方向、运动后连接方向及其折中方向构成，限制在相对垂直方向 ±60°；比较原截面和几何目标最好的至多三个候选。先按规则种类和缺陷量选择，再比较目标。不存在通过候选时保留较好候选并标记，不把它声明为已满足规则。实时拖动使用轻量几何反馈，后台补规则检查；松开后的完成帧使用完整规则。角度搜索是有界启发式，不是连续角度全局最优证明。

### 计算过程

对位于原图点 $P$ 的材料，所属 DIE 的刚体变换记为 $T(P)$。两个共用截面位置为 $P_0,P_1$，沿追溯路径指向固定端的单位法向为 $n_0,n_1$。斜截面使用有向距离：

$$d_0=n_0\cdot(P-P_0),\qquad d_1=-n_1\cdot(P-P_1),\qquad t=\operatorname{clip}\left(\frac{d_0}{d_0+d_1},0,1\right).$$

$d_0,d_1$ 的单位为 μm；分母非正或截面交错的分区被拒绝。垂直模式继续用名义弧长比 $(s-s_0)/(s_1-s_0)$。一阶、二阶分别使用：

$$w_1=1-3t^2+2t^3,\qquad w_2=1-10t^3+15t^4-6t^5,\qquad P'=P+w(T(P)-P).$$

$s$ 为点投影到原图路径的弧长，$s_0,s_1$ 为保存的端点弧长。$w$ 为无量纲权重；0/1 权重直接采用原坐标/刚体坐标，避免浮点加减导致接缝不一致。直线/圆弧与必要的回头连接继续按 V39 的对应交点/切向构造。

设 $\Gamma_0,\Gamma_1$ 是实际 A 区两条侧边（不含切面和刚性孔盘），重构区优先比较：

$$W_A=\min_{P\in\Gamma_0,Q\in\Gamma_1}\|P-Q\|.$$

对每个交点的两侧实际边界切向 $\hat t_{ij}$，及截面方向 $\hat c_i$，两侧平均比较：

$$\alpha_{ij}=\arccos|\hat c_i\cdot\hat t_{ij}|,\qquad \max\big(\min_{i,j}\alpha_{ij},\;\operatorname{mean}_{i,j}\alpha_{ij}\big).$$

两个向量均归一化，$i$ 枚举截面/交点，$j$ 枚举截面两边。这里是无向直线的较小夹角，范围 0–90°；兼顾两边，避免一侧很尖。互补内角不能同时都变为钝角，不把这一几何矛盾隐藏在“平均”名称下。曲线使用其实际离散边缘切向，不用连接端点的直线替代曲线切向。

## 概率、绿色与灰色的边界

对一个动区 $a$，其线宽、线距、包围量、连接等任一失败事件的并集为 $E_a$：

$$p_a=\int_{\mathcal H}\mathbf1_{E_a}(z)f_T(z)\,dz,\qquad \overline p_a\le 2\Phi(-k).$$

$\mathcal H$ 是用户硬输入偏移范围，$z$ 是全包各 DIE 的 X/Y/角度联合状态，$f_T$ 是该范围内归一化的联合截断正态密度，$k$ 为良率级别，$\Phi$ 为标准正态累积分布函数，$\overline p_a$ 为可信上界。有限非零级别才允许按上界降为灰色；0/∞不降级。手动超出输入分布范围的姿态按几何事实标红。

每轴 0/最小/最大构成的有限离散目录覆盖全部离散组合，因子分解保留同 DIE 共享姿态及不同 DIE 的组合关系；并非只检查所有芯片同号移动。零幅度轴仍锁零。**离散绿色不代表节点之间的连续空间已证明安全。**

代表极端的概率单元按相邻中点划分，单元质量由截断正态积分得到并保留 X/Y 相关性；单元内用代表姿态归类，得到的是近似估计，不是低概率证明。一般复杂形状的连续上界保留为 1，不能因“样本未命中”变成灰色。

连续上界只在可证明的受限情形启用：单条矩形直导体、无旋转、静态邻网、孔盘完整位于刚体端、直线/一阶/二阶连接等。令原图最小净间隙为 $m$、过渡长度为 $L$、盒内平移上界为 $D$，位移梯度上界 $\ell=cD/L$，其中 $c=1,1.5,1.875$。检查 $\ell<0.35$、$(1-\ell)m$ 大于规则及离散误差余量，同时检查邻网、封装、禁布区和孔盘包围量。二分找出可证明的中心安全盒；其概率质量 $M$ 给出 $\overline p_a\le1-M+\epsilon$，$\epsilon$ 包括质量积分误差和数值余量。自动角度模式必须保留这一已通过的原截面候选，规则优先不得选用失败替代。曲线回绕、复杂源图、多动态邻网等不满足充分条件时保持未定，不作灰色证明。

整包“重构良率”仍按完整有限网格的实际铜形规则并集积分；它和单动区的连续上界证书是两类结果，不能混为同一精度。

## 忽略、保存和缓存

普通右键菜单在开启重构预演后增加“忽略选中图形的重构”和“取消忽略选中图形的重构”。忽略按完整源图形进行，其原始固定铜保持不动，没有动区填充；该铜仍作为其他网络的障碍，也仍计入整包规则良率与极端筛选；原有违规不能因忽略重构而被豁免，当前实际问题仍单独标记。

工程 schema 保持 5。新设置 `reconstruction_boundary_mode` 缺省为 `perpendicular`；`ignored_reconstruction` 保存源 GDS SHA-256、Top Cell 和图形引用，旧工程缺省空集合。图形索引合并时迁移忽略引用；不同源指纹不得误用。内部 settings 的忽略字段不能越过源绑定验证。

缓存键包含连接样式、角度模式、共用位置、工艺及忽略集合。切回已有条件复用结果；在途任务取消传递到几何线程及缓存等待，旧结果不得覆盖新条件。规则归因范围按实际几何引用缓存，编辑后自动失效。相互作用先按共用 DIE 状态匹配，再做空间查询：例如两个各含两颗 DIE 的因素共享一颗时，27²×27² 个无约束配对先减少到 27³ 个兼容配对；不是删掉可能组合，也不代表壁钟时间必然加速27倍。原生数据库访问目前串行，前端规则阶段至多两线程，其他几何阶段仍按硬件配置调度。背景极端/良率检查等待当前预演规划完成，再克隆其路径与独立可变缓存，避免两次冷规划。

DXF动静区输出优先冻结当前已完成图形。逐层并行分类、临时顺序缓冲后流式写出；保留开放折线、完全一致的共享端点、无内部截面/HATCH、失败不覆盖旧文件。输出的 A/B/C 来自当前姿态与当前角度模式，红色提示图形不是铜。
