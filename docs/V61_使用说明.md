# V61 动静区 DXF 与 SH22 过孔随动

在「输出」中选择「动静区输出」。导出几何使用名义零位，当前极端姿态可以继续留在画布上。

| DXF 层名 | 轮廓 |
| --- | --- |
| 固定 RDL 层名 + `_A` | 随运动过孔一起移动的区域 |
| 固定 RDL 层名 + `_B` | 固定过孔端的区域 |
| 固定 RDL 层名 + `_C` | 两端之间的适配动区 |
| `RKG_REF` | 封装边框 |
| `DIE_REF` | 芯片边框 |

固定 RDL 只输出真实外缘与孔洞边缘。每个源图形在同一输出层上的线段组成一个 CAD 块，各层分别插入。参考边框保持完整闭合折线。完全重合和局部重合的铜轮廓只保留一份。两个参考边框若共用一段边，导出会提示冲突并保留已有 DXF。旧工程中的图层和设置继续可读，旧结果侧车需要重算。

SH22 的三个位置可通过单颗芯片手动偏移复核。DIE 2 驱动 `(-240910, 246311)`，DIE 1 驱动 `(-243387, 245147)` 和 `(-242996, 245508)`。显式连接到运动侧端口的跨芯片扇出仍使用该端口归属。
