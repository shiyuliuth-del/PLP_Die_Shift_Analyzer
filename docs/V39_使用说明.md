# V39：连接样式、规则反馈与重构良率

“设置 → 重构预演 → 连接样式”提供直线、一阶、二阶、圆弧。旧工程缺少此字段时使用二阶，保持 V38 的过渡含义。修改立即更新重构，并保存到 schema5 工程；不同样式、端点、规则分别缓存。手动边界依然绑定原图，所有工况共用，另一端不会随本次拖动重新选择。

| 样式 | 连接含义 |
|---|---|
| 直线 | 将运动端两交点作真实 DIE 变换，按原图边界侧别分别连接固定端对应交点，形成四边轮廓。 |
| 一阶 | 原材料位移采用三次权重；过渡端的位移一阶导数为零。 |
| 二阶 | 原材料位移采用五次权重；过渡端的位移一、二阶导数均为零。 |
| 圆弧 | 用两段相切圆弧连接边界交点，并匹配两端原边界的切向。一般四端条件不能由单个圆满足，因此使用双圆弧。 |

蓝色运动端、黄色固定端都支持整孔盘圆点模式。实体孔盘保留原尺寸，接线发生在孔盘外的真实截面；圆点只是拖动柄，不是零宽导体。两种点都向自身分支偏移，多个分支共用一个孔盘时在屏幕上保持可分别点中的距离；显示偏移不改变电连接、旋转或DXF坐标。拖离孔盘可恢复线柄。

能够以真实截面隔开固定末端的树状分支，分别建立路径和两个端点，共用的运动主干只作一次刚体运动。同一层、同一图形、同一DIE的不同分支用路径指纹分别保存。无法分离的环路、多DIE交叠归属等仍警示保留源图，不凭最近孔心制造切分。

原图的端点弧长始终有序，不能交换A/B/C的材料身份。“交错”指偏移后画面中的两侧端点相对位置。直线拖动到贴紧处限位；某极端本来就使端点反向时，不强行连成折叠四边形。一阶、二阶、圆弧会在有限候选中尝试回头弯：三次/五次贝塞尔中心线与宽度轮廓，或分段相切双圆弧。端部匹配真实边缘方向，内部不得自交或从截面以外侵入刚性孔盘。圆弧在计算与DXF中按源精度离散为直线轮廓，不启用圆弧恢复。

有合法连接而规则仍不满足时，保留所选样式中当前有界搜索找到的较好候选。不能形成有效连接时移除失败的连接段，保留真实运动端、固定端及整孔盘；用红色半透明区域提示断开位置。红色区域仅是可选标注，绝不输出为铜。无法建立可信分区时仍保留源图并标明原因。

令原图边界点为 $P$、其名义路径弧长为 $s$，动区端点为 $s_0,s_1$，刚体变换为 $T(P)$。一阶、二阶使用

$$t=\mathrm{clip}\!\left(\frac{s-s_0}{s_1-s_0},0,1\right),\qquad P'=P+w(t)[T(P)-P],$$
$$w_1(t)=1-3t^2+2t^3,\qquad w_2(t)=1-10t^3+15t^4-6t^5.$$

$s,s_0,s_1$ 单位为 μm；$t,w$ 无量纲。全孔盘时 $s_0$ 取原孔盘末端弧长，之前的孔盘保持刚体运动。导数连续描述的是附加位移场，不能将原图已有尖角称为自动变成光滑曲线。

## 拖动与检查

- 两色边界、两种圆点均从静态背景中移除后重画，拖动不留下旧位置残影。圆点与线柄在悬停及拖动期间持续脉冲；移开、取消或关闭功能后停止。
- 即时几何反馈和规则检查分开：前台合并连续鼠标事件，后台检查最新完整重构铜。过期检查不能覆盖新位置；检查期间不宣称已经通过。
- 检查固定 RDL 有效线宽、线距、连接过孔的固定 RDL 包围量、封装边距及禁布区。有效线宽／线距为工艺值减去共用 DRC 容差；包围量不减此容差。线宽／线距沿用原生近似平行且非相邻边规则，实际异网交叠也判失败。
- 问题动区用红色半透明填充；单击问题区域显示与宽度菜单一致的浮动菜单，列出图形、分支、当前偏移、连接样式及失败原因。粉色仍定位原生规则见证。直线贴紧限位之外，手动端点保留，不暗中修改另一端或把违规图形当作合格结果。后台检查完成后只更新最新姿态。

自动选择比较最多三个较长的候选区；每个姿态比较基准连接与至多七个保留样式的回头候选，先降低局部规则失败的概率质量，再考虑合法几何次数和长度。局部排序用每轴三节点的截断分布单元质量，保留 XY 相关性；邻网在此排序阶段采用名义参考铜，并另做全输入保守包络检查。因此它是有界候选启发式，不是整包最优布线或连续空间全通过的证明。手动区也报告局部失败质量；整包良率另用实际重构邻网计算，二者不能互换。

## 重构良率

启用重构后，画布上方、与坐标相同的一行居中显示一项“重构良率”。宽度分析同时开启时，两类数字在同一行显示；不会挤占画布高度。这里不使用“假设红黄全部修正”的策略，而是检查实际重构后的固定 RDL。

$$Y_\mathrm{recon}=\sum_{\boldsymbol j}\left(\prod_d m_{d,j_d}\right)\mathbf1[\text{该整包姿态全部已列规则通过}],$$
$$m_{d,j}=\int_{C_{d,j}}f_d(x,y,\theta)\,dx\,dy\,d\theta.$$

$d$ 是 DIE 编号；$j_d$ 是其有限网格节点编号。$C_{d,j}$ 由相邻节点中点划分，端点落在用户输入的最大偏移边界。$f_d$ 是范围内归一化、保留 XY 相关的截断联合正态密度。不同 DIE 的输入分布按现有模型独立，同一 DIE 的所有图形共用同一姿态。$\mathbf1$ 为联合通过指示函数。全零幅度轴锁零，0／∞ 级沿用最近有限非零概率尺度，首次默认6。

“良率积分每轴节点”默认3，可设3–9。完整有限网格按电网络及可能相接的网络对分解，最后合并失效事件；不把各过孔通过率相乘。存在一个网络在全部局部网格姿态都失效时，可直接证明该有限联合网格的良率为零，无需重复计算其他因子。始终单独累计失败质量，极小尾部不会被 `1−Y` 的浮点相减抹掉。显示精度共用宽度良率小数位数。

数值为模型估计（前缀“≈”），不等于真实生产签认。完整有限网格不等于穷尽连续空间；增加节点数可检查分辨率误差，窄失效区仍可能落在节点之间。所列规则之外的制造缺陷、未重构运动层的全部工艺规则、最小内角及物理应力不包含在这个数中。缓存依赖图纸、工程节点、连接、规则、分布、样式、共同端点及网格；当前显示姿态和显隐不改变整包概率。

## 显示完整性与资源

多颗 DIE 引用同一源铜时，静区先合并再绘制，不再因只保留第一份静区而漏画。GD55 指定位置 `(-1164,-127)` 对应旧导入索引的 `5/0` 第18个源图形；V39合并后按来源映射定位，不能沿用旧数值索引。实际显示分区的并集必须等于最终替换铜；不会用只画第一份静区来代替共同静区。

极短过渡只在权重改变的边界段细分，刚体孔盘和固定端不按微小过渡长度密集采点。原生布尔检查在找到违规后不再生成全部标记多边形；正式违规显示仍使用完整几何结果。耗时计算有进度、取消和过期结果检查；精确几何和 DRC 保留 CPU／离线桌面 KLayout 后端，不宣称未经实机验证的 GPU 提速。

## GDS完整图形与旧工程

读取层级并完成几何修复后，同一layer/datatype中有面积重叠或公共边的碎片Merge为整体；仅一个点接触的不强行合并。孔洞保留，用往返桥接轮廓保存节点，计算仍使用含孔洞的有效多边形；不填孔、不按最大节点数重新拆小图形。后续选择、Q编辑、连接追溯、预演和输出引用同一个整体身份。

schema5新增可选的 `geometry_indexing=merged-v39` 与 `legacy_node_edits`。旧工程的逐片Q编辑先施加到旧索引源，再Merge；旧忽略记录和孔引用映射到完整图形。现代工程的Q编辑施加于合并后的整体。旧路径因合并改变时，保留旧设置记录但重新选择不匹配的路径，并输出提示；不能静默将旧弧长套到另一条线路。源GDS不写回。

## 动静区DXF

Point／MultiPoint等零长度交点不会进入递归折线拆分，避免原来的递归溢出与PEP3118错误。仅输出实际实体的外轮廓和孔洞轮廓，不输出A/B/C内部切边、不输出HATCH。相交处使用共享坐标池，同一交接端点重复使用完全相同的浮点数，因此DXF文本坐标一致。整个闭合轮廓即使属于单一层，也拆为两条开放折线；每个实体的首尾不同且closed=False，叠加才还原完整边界。失败保留原目标文件。
