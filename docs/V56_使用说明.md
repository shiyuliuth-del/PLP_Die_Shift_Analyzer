# Die Shift Analyze V56

## 本轮修复与新增

- **随包测试案例**：正式源码包及构建脚本新增 `Jobs/GD55_1119`（含 `GD55_1119.gds` 与 `GD55_1119.dshift.json`），与原有 `Jobs/GD55` 一起随包发布。
- **多 DIE 共网边界拖动与拐角追溯修复**：
  - 修复双 DIE 无固定过孔线路在固定 50% 归属缝处无法跨过中点继续拖动的问题（如 `GD55_1119` 位置 `(670, -1854)`），在保持各 DIE 动区互不重叠的前提下允许沿实际静区空间双向拖动。
  - 修复无固定过孔多 DIE 线路被内部短弦截断在拐角处的问题（如 `GD55_1119` 位置 `(1211, -1769)`），自动动区沿完整可达锚点路径选取长直段，可顺畅跨过拐角拖动，删除动区（含框选动区）立即生效，并在左侧自由/符合边界角度框选均可正常创建动区。
- **框选动区落点标记**：进入「框选动区」模式后，鼠标在画布内移动即显示类似 K 测量模式的十字落点标记，确定首点后同时标出起点与当前落点，移出画布或退出模式自动清除。
- **关闭自动计算时的操作反馈**：即使关闭「自动计算」，拖动边界、框选动区、右键删除/增删动区、忽略/取消忽略、整块静止/随动、以及固定过孔随动设置均立即在画布上以虚线高亮标记受影响的图形、过孔或选框，并在状态栏给出清晰提示，待点击「重构计算」统一计算。
- **多动区图形弹窗优化与点击提速**：重构预演单击包含大量动区的图形时，自动隐藏当前视野范围外的动区弹窗，视野内不再强行大量叠加，同时向量化弹窗避让布局并缓存替换图形路径，显著降低点击延迟。
- **重构预演性能优化**：向量化截面求交、加速路径分区校验与候选均匀宽度筛选、按物理层复用异网空间索引并扩大原生计算缓存，提升重构规划与非零姿态求解流畅度。

保留 V55 全部导入分批合并、固定过孔联动（关闭 / 全局模式 / 分别处理）、自由框与符合边界角度框持久化、零位行跨页汇总及实测客户端 `RealDataAnalyse` 联合发布规则。详见 [V55 使用说明](V55_使用说明.md)。
