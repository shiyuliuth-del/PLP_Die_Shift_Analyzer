## 整合方法与保留范围

以已核对的 main 整树为基础，先用多父合并提交记录四条来源历史，再逐功能移植和修复。来源提交均为整合分支祖先，既不丢来源历史，也不把旧文件整份覆盖当前主线。多父提交本身不宣称每一行来源代码都进入最终运行树。

保留 main 的两项宽度良率及概率、禁布区、独立过孔范围显隐、忽略线路、极端表筛选/分页、DXF参数与工程存储、硬件关闭保护及 CPU 回退。保留 RUN.bat / BUILD.bat、无版本锁依赖、驱动式 GPU / PTX、构建图标及体积检查、源码归档白名单和独立 `--gpu-info` 诊断。

不采用来源的 V27 README/规范回退、CuPy 运行库打包配方、重复 Windows 启动入口、旧测试脚本和运行日志。它们在来源历史中仍可查阅。

## 本分支可用的新增与修复

- 保留当前双刀流程，同时恢复可用第一刀的拖动及每次 5 μm 微调。第二刀平移、每次 5° 旋转和独立复原共用正确的第二刀保存字段；“清除全部手动切口”清理第一刀、第二刀、旧额外刀及删除标记。
- 重构页增加“框选动区 / 框选静区 / 清除全部手动区域”。矩形只写入当前重构结果里可见的固定 RDL 图层。静区优先，但所属落盘保持随动；同块铜涉及多个 DIE 时，只有归属明确的动区才应用，歧义数量明确提示，不能把同一块铜重复分配给多个 DIE。关闭重构、切换工程、M 模式、Escape 均退出框选。
- 手动区域、所有切口及删除标记随 schema 5 工程往返保存。旧工程缺省为空；拒绝非有限坐标及无面积矩形。普通设置操作不再丢失未显示为控件的手动字段。改变重构参数或编辑会刷新缓存并标记旧评估证据失效。
- 过孔身份使用 `(图层, 图形索引)`，旧的纯索引仅在没有跨层歧义时兼容。保留 `targets` 子集入口并增加目标索引；块缓存有界且每实例隔离。修复完整帧缓存键被其它局部变量覆盖，保证同姿态命中；quick 帧不写入完整帧缓存。
- 恢复完整重构后异网铜的实际最近净距，远于局部冲突半径时不再用搜索上限冒充测量值。补充双刀、固定孔停止距离、最小刀宽回退、区域与分层身份、缓存/quick-full 的独立测试。

## 模型与验收边界

本分支沿用实际 main 的双刀模型，并不是将旧 V37 使用说明中的有限单刀搜索重新作为唯一模型。重构是当前姿态下的几何假设，不代表整图 DRC、全局可布通或量产良率。手动区域只作用于重构，不修改源 GDS 或名义宽度概率。

原 main 的近期上传没有同步全部旧测试及使用文档。本轮先在原 SHA 的独立工作树执行基线，再用同一环境复测整合结果，明确区分继承失败、新增回归和环境限制；没有删除旧断言来冒充全绿。

Windows 原生构建、真实 NVIDIA/CUDA、外部 GD55 图纸及 KLayout 桌面后端均需有实际环境才可验收。Linux offscreen 和 KLayout Python 模块通过不能替代这些项目。原有已知问题继续见 [KNOWN_ISSUES.md](KNOWN_ISSUES.md)。

当前继承的 `reconstruction_second_turn_deg` 在算法中只读取、未实际参与自动第二刀搜索，不应当作已实现的转角阈值。没有为使旧测试通过而恢复一个不同的单刀模型，也没有删除旧测试。旧 V37 文档的单刀距离与搜索描述只供历史参考。
