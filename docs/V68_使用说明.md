# V68 使用说明

## RealDataAnalyse

- 「信息读取」包括 Excel 文件、Excel 列映射和 Mark 信息。Excel 文件和 Mark 信息默认显示，列映射默认收起。展开后可编辑原有映射。Mark 信息预留一行一个 Mark 的表格，并提供模板图纸入口。
- 在「任务运行」中创建、运行和恢复任务，查看封装记录。「忽略测量失败」也位于这一页，默认关闭。
- 「忽略阈值」要求封装内全部 DIE 的 X/Y 偏移和旋转绝对值严格低于各自阈值，满足时以名义原图输出。「忽略DRC」使用独立阈值，符合条件且仍须重构的封装跳过普通 DRC，仍执行连通、异网接触和禁布区检查。两组开关均默认关闭。
- 底部进度条常驻显示开始时间、总耗时、计数和达到 FAIL 判定的封装数。安全停止或异常退出后重开原项目，选择「运行 / 继续补算」恢复。自动补算会完整重放未提交批次，进度追平后继续更新。改变工程或执行阈值后需创建新任务。

预演软件界面和逐层补偿操作参见 [V67 使用说明](V67_使用说明.md)。
