# V66 使用说明

## 动静区 DXF 图层与自动 JOIN

- 动静区 DXF 输出时，不仅 CAD 块的 `INSERT` 位于对应 `_A` / `_B` / `_C` 图层，块定义内部的所有轮廓实体也一并赋予该块对应的 ABC 图层（不再放在 `"0"` 层）。
- DXF 输出参数新增「动静区自动JOIN」（默认不勾选，保持开放分段）。勾选后，每个动静区 CAD 块内首尾相接的多段线自动合并为一条长多段线，闭合环以闭合多段线输出；回读校验同样检查坐标、闭合、重复和重合。

## 工艺面板与避让空间默认项

- 左侧「工艺」菜单中的所有栏目（线宽线距、过孔包围量、图形过滤、芯片距离、其他）默认全部展开，便于直接查看与调整；已保存工程中显式记录的展开状态仍按原设置恢复。
- 「避让空间」输出间隔（APD 离散步长）默认值调整为 `100` μm。

## 关闭自动计算时的删除 / 撤销删除与工程导出

- 关闭「自动计算」后，执行图形删除（`Delete`）或撤销删除（`U` / `Shift+U`）不再立即触发几何重建、评估与重构计算，而是在画布保留特殊暂存标记（「待算：删除图形」红虚线框与「待算：撤销删除」绿虚线框），直到点击「重构计算」时按操作顺序统一应用并计算。
- GDS/OAS、普通 DXF 与动静区 DXF 导出均反映用户对版图的节点编辑和图形删除；存在未计算的暂存修改时会提示先完成重构计算，避免导出旧几何。
- 保存工程会完整记录用户的节点修改与删除记录并在重开时自动应用，绝不修改原始 GDS/OAS 文件。

## 实测输出与大型图纸性能优化

- 实测输出模式关闭无关界面定时器与低频冗余锁定刷新，支持按可用 CPU 核数与内存上限提升多进程并发，并在逐封装变化 `rotation_center_um` 时复用线程内 `ContactModel`、`Reconstructor` 与 `GlobalDRC` 缓存，且缓存名义静态多边形 WKB 与同归属孔盘包围计算。
- 实测批量输出中，对平移与旋转均为 0 的 DIE 跳过对应静止重构位置计算（带异网碰撞回退保护），经真实案例对比确认几何 XOR 为 0、DRC/失败目录完全一致且显著提速。
- 大型图纸导入的最小面积/最短边长过滤改用 C 批量多边形构建与向量化短边检测；动静区轮廓拆分跳过纯静态区并优化重边检测；编辑包含大量动区的单个金属图形时复用局部缓存、加速分叉组装，并在关闭自动计算时对多动区图形异步刷新草稿预览，避免界面卡死。
- 修复 SH22 拐角（如 `(-241542, 245414)`）在一阶连接拖动时因布尔差产生 `GeometryCollection` 导致 `'NoneType' object has no attribute 'difference'` 弹窗报错的问题，以及部分源无替换铜时重构良率 `KeyError` 报错的问题。

其他常规操作与 RealDataAnalyse 客户端用法参见 [V65 使用说明](V65_使用说明.md) 与 [V64 使用说明](V64_使用说明.md)。
