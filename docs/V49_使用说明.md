# V49 开发中的操作与接口说明

当前为联合开发候选，尚未发布。最终验收完成后更新本文件。

K进入标尺测量，左键拖动或依次点两个端点；Esc退出，Shift+K/Ctrl+K清空。黑色双箭头数值单位μm，随工程保存，作为注释不参与铜、DRC或导出。

尺寸容差正值放宽、负值收紧，扩展至线宽、线距、两种包围量、机械净距和图形距边框。重构生成预留DBU余量，验收统一使用有效尺寸。安全范围仍用于主动进入结果分析后的连续安全盒计算，保留。

极端表用行号替代原第一列，检查通过浅绿、尺寸DRC违规但可连接浅黄、无法连接浅红，未检查不着色。右侧“显示DRC问题”控制标记；问题列表每页256行，按行定位当前问题。测量/新框选和旧工程迁移正在验证。

框选动区在名义源图形上严格裁切；按住左键滚动滚轮可绕当前鼠标旋转选框，继续移动保持该角度。若选框不分离运动/固定路径，不能扩大选框伪装成功。旧静区字段兼容读取，相关按钮退役。

连接失败改为运行信息和诊断预览；失败适配铜留断口，双侧红色虚线仅作指示。普通制造导出不接受诊断图。批量可明确请求output_policy=omit_failed_regions，经局部删除及独立无异网接触检查后继续；返回partial_output和遗漏区域信息，不把失败变成正常连通。

每个实测姿态计算其实际铜的完整DRC并返回所有位置，不计算其他姿态、概率或良率。问题带bounds_um、die_ids（1起；0公共）、封装相对范围；批量还给TopCell范围。大目录用task.issues分页，完整条目保存在项目Cache/MeasuredDiagnostics.sqlite。另一窗口负责OAS的ERROR命名层、DIE Cell矩形、客户端策略及GD55压力表，接口整合后补充最终使用示例。
