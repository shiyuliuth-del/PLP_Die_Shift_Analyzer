# V49 使用说明（联合验证中）

本轮包含此前14项主程序修改、实测完整问题回执及RealDataAnalyse联合修改；未完成全部验收前不视为正式发布。

## 交互

- 结果图形中按K进入测量：拖动或依次点击两点，绘制黑色双箭头及μm数值。Esc退出，Shift+K或Ctrl+K清空。测量保存在工程，不进入制造图纸；旧工程默认没有测量。
- “显示DRC问题”控制当前实际铜的完整DRC标记。表格每页256行并有行号；分页不裁掉画布问题。隐藏图层只改变显示。
- 极端情况保留零位首行，删除旧第一列，行标题为编号。上方仅显示页码和所选范围总行数。浅绿表示已检查没有问题，浅黄表示有尺寸DRC但仍连通，浅红表示无法生成保持连接的图形，未完成核验不冒充通过。缓存数量不再改变颜色。
- 框选动区严格取选框与名义源铜的交集。按住左键并滚动滚轮可绕鼠标旋转，后续拖动保持旋转角度；非零姿态先复原。不能切断运动—固定路径的局部框明确标记失败，不自动扩张成另一个区域。保留删除/撤销手动动区按钮，删除旧框选静区、清空区域和两切口按钮。

## 规则与重构

尺寸容差统一用于线宽、线距、运动/固定包围量、芯片机械净距、铜距封装边。正容差放宽、负值收紧；距离最低为0，不能穿入边界或异网。生成线宽/线距保留输出量化余量，检查阈值使用同一有效尺寸。良率分布不因容差改变。

约束冲突时候选按严重度排序：异网接触/禁布区不可进入；其次优先保住线距，再包围量，再线宽，最后内角。此为有限候选的确定性排序，不宣称全局布线最优。近距离平行直线先尝试共同名义截面，手工位置仍保持身份。真实固定孔中心用于追踪，避免用复杂孔盘内部代表点使直线方向偏离。

无法保持电连接时记录错误并显示该姿态：正常铜保留，失败连接段删除，两个边界对应点以双侧红色虚线连接。诊断画面不当作正常制造结果输出。没有可编辑连接段的不可动短路保留明确源身份/问题范围，不虚构一条连接路径。

“安全范围”仍是结果分析按需计算的连续安全盒参数，确有调用入口，因此保留；没有进入结果分析时不计算。

## 实测回执与部分输出

每个指定实测姿态检查全部实际铜的DRC与连接，不计算其他姿态、概率或良率。问题回执提供图层、源身份、类型、点、矩形范围、相关DIE、要求值、封装相对及TopCell坐标。超出首128条的完整记录用task.issues分页读取，不截断。

批量默认strict。RealDataAnalyse显式请求omit_failed_regions时删除失败局部，保留正常铜，继续其他封装，并在ERROR层按DIE子Cell绘制问题矩形。低于输出格点、不可表示的碎片直接删除；正常可表示的铜保留，源文件不改。量化后再次检查异网隔离；连接失败事实不因部分输出变为成功。软件、通信、磁盘和不可修复的无效几何仍返回错误。

接口字段和可执行示例见[实测API](MEASURED_OUTPUT_API.md)，协作合同见[V49错误输出](V49_ERROR_OUTPUT_CONTRACT.md)。
