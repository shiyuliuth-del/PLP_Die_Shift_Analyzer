# Die Shift Analyze V73

- 同一网络的不同支路按实际穿越选框的区间分别建立动区。自由框在分支或归属接缝缺失截面时，尝试在选择的局部路径补齐。未找到有效截面时，该位置保留诊断。
- 型变前相互分离的支路在型变后发生接触时，重构记录连接失败及具体位置。正式输出执行相同的连接门禁。
- 单击动区间的铜段即可选中，包括两条边界命中范围覆盖的短段。拖动仍移动边界；浮动铜段可通过右键更换随动策略。
- 动静区 DXF 输出名义实体的边界和孔洞轮廓；只把有效动区用于 ABC 分类。失败诊断的图形不生成额外分割线。
- 「孔盘整体触发」与「积分精度」并列。前者仍用 μm，后者仍为每轴节点数。原工程的参数字段与保存值继续适用。

验证坐标为 SH22 的（−242577, 246167）、（−241964, 245429），单位 μm。验证包含自由框局部修正、相邻分支独立、偏移后的同网接触诊断、短段点选及 DXF 回读。

Windows 可用包中两份启动脚本运行 Die Shift Analyze 与 RealDataAnalyse。需要本地打包时运行 `BUILD.bat`。
