# Die Shift Analyze V51

单击「结果图形」画布后，用 ←、→、↑、↓ 朝对应方向查看版图。每按一次平移当前可视宽度或高度的 20%，缩放比例和芯片偏移均不变。表格获得焦点时方向键仍用于选行；直接拖动重构边界时不会误移视口。K 启用十字标尺，单击两次测距，中间可按中键拖动画面，Esc 退出。

极端表的筛选为「全部显示」「DRC问题」「连线失败」。DRC 包含连线失败；仅连线失败不包含尺寸告警。旧工程的过滤开关映射为前两种相应状态。工艺中的原「DRC」「机械净距」现为「其他」「芯片距离」。输出按 GDS/OAS、DXF、实测输出分组。

关闭重构自动计算后可以先编辑边界、框选、增删或忽略动区；待应用源以临时描边标明。按「重构计算」才重新核验。手工框以所选源铜为界；拖动边只移动该侧。多端共用动区保留实际端口，只取近端代表控制柄。最小内角按材料一侧计算，孔和外环分别处理。

「硬件与计算资源」可设置线程和内存上限，0 表示自动。联合姿态核验按资源预算分配独立工作单元；具体吞吐取决于版图。实测客户端、GD55 模板及随包输入见 [GD55 验证说明](GD55_MEASURED_CASE.md)。前版操作见 [V50 使用说明](V50_使用说明.md)。
