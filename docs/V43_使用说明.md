# V43 使用说明

本轮增加实测本地遥控与批量OAS输出，并修改动区拖动、等宽自动选区、面积过滤和忽略模式。接口详见[实测命令文档](MEASURED_OUTPUT_API.md)，验证边界见[验收记录](V43_VALIDATION.md)。

- 打开按钮为“打开GDS/OAS”，两种格式共用几何修复、Merge、用途和工程逻辑。
- 工艺 → 图形过滤 → 最小图形面积（μm²），默认0。严格小于阈值的图形删除、小孔洞填去；当前打开图纸同步重建，显示、连接、评估和导出一致，源文件不修改。降回0可重新取得未编辑源图形。
- 自动动区在工艺风险优先的前提下，优先近似等宽区段；鼠标从倾斜边界任意位置按下，按相对移动量拖动，减少单向死区。
- 忽略固定RDL默认整块静止。右键可选“忽略图形：整块随动”，以浅紫色区分；同一块连接的多个DIE若变换不同，则不能同时刚体跟随，保留原图并报告失败。
- 修复补块功能和标签页不再保留，旧工程相应字段忽略。
- 输出 → 实测输出，填写输出目录、资源上限并勾选。软件先自动保存工程，再完成必要评估。开启期间工程编辑锁定，其他Python可通过认证本地IPC查询/切换工程、提交全部DIE姿态及中心、显示单姿态、导出GDS或批量OAS，收到每项任务状态。
- 批量不会逐姿态刷新窗口，按内存预算分块写同一个临时OAS，复用几何Cell，结束时生成排列全部封装的TopCell。完整DRC/概率不在快批中执行，失败连接默认拒绝输出；诊断导出需显式允许并核对错误明细。
- 取消为合作取消，等待正在执行的原生调用安全返回。关闭实测输出恢复工程参数和零位预览；接口默认不随工程开启。

Windows仍用RUN.bat运行、BUILD.bat在目标机器打包，不联网补装、不发布EXE或用户图纸。V43另提供独立接口MD和GD55-1105验证PY，便于外部程序接入。
