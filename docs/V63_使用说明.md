# V63 使用说明

## 自动载入测量表

选择项目文件夹后，RealDataAnalyse 将 `RealDataAnalyse/Excel` 下的测量表加入界面的 Excel 文件表格。支持平铺的旧式 XLSX，或每颗 DIE 一个子目录，目录内的 CSV 和 XLSX 共同参与导入。若解压多出一层 `Partition0`，可以保留该目录。刷新项目时，新复制的文件默认勾选，原有勾选和主动删除的行按项目保存。

点击「创建任务」后匹配并核验实测记录。一颗或多颗 DIE 缺少有效实测姿态时，会记录封装编号、来源行及对应芯片。详细记录保存在项目任务库中，其他完整封装继续处理。

「连接与工程」中的「忽略测量失败」默认关闭。勾选并创建任务后，对于机台标记为失败的芯片，使用该行「偏移X」「偏移Y」「旋转角度」填写的数值，芯片中心由理论中心加上本行偏移得到。相同位置有可用的成功测量时优先采用成功行。失败行仍须具备明确的理论位置和有效的偏移与角度。每条实际采用的失败行记录在任务库中，设置随项目和计划任务保存。

## 原图直出阈值

在「连接与工程」设置 X、Y 阈值（μm）和旋转阈值（°）。每个封装中所有 DIE 的绝对 X 偏移、绝对 Y 偏移、绝对旋转角度都必须严格小于相应阈值。生产格式的偏移由实际中心减理论中心；旧式 XLSX 使用映射的偏移值。相等或超过任意阈值时，该封装按实测姿态重构。

满足条件的完整封装按理论封装位置引用同一个 `G_NOMINAL` Cell，保持名义芯片边框、铜和其他原图层。任务结果标记「原图直出」，不会将其计为已检查实测 DRC。任一阈值设为零时关闭该选项。阈值随项目保存，计划任务使用创建时的快照。启用阈值处理 V62 及更早创建的生产格式任务，请先重新「创建任务」。已执行过的任务更改阈值后也须重新创建。

## Windows 启动

使用根目录 `DieShiftAnalyze_RUN.bat` 或 `RealDataAnalyze_RUN.bat`。`BUILD.bat` 一键构建两个 EXE 到 `dist` 并复制两份启动脚本。两份脚本优先查找同目录及 `dist` 内的 EXE。其他工程操作参见 [V62 使用说明](V62_使用说明.md)。

## 工艺和 DRC

在「工艺 → 其他」设置最短边长、最小铜图形内角及尺寸容差。打开旧工程时继续读取已保存的值。「设置 → DRC」中的检查类别、显示开关和标记样式仍在原处。

## 实测输出

启用实测输出后，主窗口不显示进度条。需要停止任务时仍可使用取消按钮。IPC 客户端可查询任务状态、批次完成数、DRC 目录和错误信息；RealDataAnalyse 仍按批次完成数反馈进展。

## 重构预演

在同一计划下切换姿态时，重构复用名义动区分区及边界几何，将算力用于当前姿态的适配和最终铜形核验。编辑动区或更改适用规则后会重新准备相关数据。

## 动静区 DXF

固定 RDL 的 ABC 层恢复 V61 的分段多段线。各段仍按原图形及所属图层放入 CAD 块，交接点使用相同坐标。封装边框 `PKG_REF` 和芯片边框 `DIE_REF` 继续输出完整闭合轮廓。
