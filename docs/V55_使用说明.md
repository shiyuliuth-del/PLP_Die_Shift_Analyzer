# Die Shift Analyze V55

## 重构边界

- 按「框选动区」，在零偏移图上依次单击矩形两个角。移动鼠标预览，滚轮旋转，Esc 可取消。下拉菜单的「自由」保留矩形边缘的角度，「符合边界角度」从框内确定位置，由垂直、重构区优先或两侧平均决定两边角度。
- 固定过孔端始终是直线。运动侧拖至所属过孔孔盘可进入圆点模式。自动规划沿真实连接保留可拖动的转弯路径，附近等宽平行线满足共同区间条件时对齐切口。
- 右键菜单仅显示一行选中摘要。「删除动区」移除当前动区，「删除全部动区」清除目标固定 RDL 图形上的全部动区并置为静止忽略，可通过「增加动区」重新开始。
- 新导入图纸默认关闭自动计算。保存工程仍会记录用户显式设置、框选模式、手动动区和逐孔随动选择。

## 固定过孔联动

| 设置 | 关联固定过孔如何运动 |
| --- | --- |
| 关闭 | 保持原位，默认 |
| 全局模式 | 名义连接到整块随动铜形的固定孔跟随该铜形 |
| 分别处理 | 默认静止，在关联固定过孔上右键选择「固定过孔随动」或「固定过孔恢复静止」 |

同一固定孔收到互不相容的刚体变换时报告连接冲突。当前姿态 DRC、显示、GDS/OAS 及实测输出使用同一实际位置。零位表格首行汇总所选组合的全部结果。红色表示连接失败，黄色表示尺寸 DRC，绿色表示完整通过。尚待核验时显示浅灰。

## 导入和资源

导入以分块空间查询重新合并 GDS/OAS 碎片，保留同层点触分离、孔洞、PATH 元数据及旧工程源索引。后台按图层并行并复用已编译几何。进程上限随 CPU、可用内存和工作量调整，实测批处理仍受用户的最大并行数和内存限制。

Die Shift Analyze 与 RealDataAnalyse 同版本发布。源码包中保留各程序的 RUN.bat 和 BUILD.bat，Windows 打包在目标电脑运行。
