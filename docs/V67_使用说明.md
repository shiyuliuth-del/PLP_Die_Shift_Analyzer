# V67 使用说明

## DRC 与撤销

- 右键点击 DRC 表格行，可选择「忽略此问题」或「取消忽略此问题」。忽略行以浅绿色显示，图上仍可定位。同一姿态的所有 DRC 位置均忽略后，该姿态通过 DRC 筛选。重构连接失败仍由电连接门禁处理。
- 忽略记录保存在工程中，与对应姿态和检查位置绑定。修改图纸或检查规则后按实际结果重新判断。实测输出继续返回原始 DRC 目录。
- U 撤销，Ctrl+U 或 Shift+U 取消撤销。关闭重构自动计算时，重构编辑、删除与恢复先更新待算标记，点击「重构计算」才应用。

## 图层补偿与边界拖动

- 「偏移 → 层叠」的「补偿」按层填写 −1000 至 +1000 μm，保留三位小数。正值沿轮廓外扩，负值内缩。GDS/OAS、DXF、动静区 DXF 及实测输出均使用补偿。计算按输入格点取整，边框也可单独设置。源图纸、预演和原始 DRC 检查仍使用工程几何。
- 动静区 DXF 在名义零位输出。轮廓扩大时将原分界线延伸到新外轮廓，收缩时由同一新轮廓重取交点。实测会在批量前准备补偿后的源图形。静止图形直接复用，刚体随动图形复用后再移动，按姿态新生成的重构铜单独做轮廓补偿。
- 「设置 → 重构预演」的「边界节点拖动吸附」默认 0，随缩放自动取距离。−1 关闭，正数按 μm 设置阈值。「吸附强度」默认 0.40，可在 0 到 1 之间调整。
- 新工程默认显示 DRC、关闭渐变插值、使用垂直边界，并启用动静区自动 JOIN。工程中已有的显式选项照常恢复。

## RealDataAnalyse

RealDataAnalyse 底部进度条常驻显示开始时间和总耗时。运行时每秒更新，即使暂时没有新封装完成也继续计时。任务结束后保留开始时间、最终耗时和完成数，鼠标悬停可查看结束时刻。

普通批量运行按封装计数，计划运行按任务计数。重试继续沿用整次运行已经达到的进度。

预演软件用法见 [V66 使用说明](V66_使用说明.md)，实测项目和阈值设置见 [V65 使用说明](V65_使用说明.md)。
