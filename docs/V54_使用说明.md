# Die Shift Analyze V54

## 重构与 DRC

- 最小内角以每个最终铜形连通分量的外轮廓为准。运动区、静区和适配区的内部拼接线及孔洞边界不参与该项。表格中的角度和问题标记使用同一轮廓。
- 同一网络可以包含一对多、多对一和多对多分支。电连接核验逐个检查物理过孔，并保留名义铜块上的端孔分组。重合点本身不能承担电连接。
- 不同 DIE 的分支共用名义连接接缝。各个动区分别适配，控制柄保持在各自的材料截面上。非零姿态用完整截面形成连接；零位保留原铜。
- 对格点级拼接缝先尝试实际铜连接，再进行完整连通、禁布和异网检查。发现无法保持连通时仍保留失败诊断。

## 性能与兼容

各物理层复用近邻索引，同一个网络的最近线距只计算一次。分叉重复截面合并后再分割，过孔完全被铜覆盖时跳过重复布尔求交。工程参数格式沿用旧版，V54 重新计算旧版结果侧车。主程序与 RealDataAnalyse 同包发布，RUN.bat 启动，BUILD.bat 在 Windows 打包。
