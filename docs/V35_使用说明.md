# Die Shift Analyze V35

## 良率显示与计算

图片上方与鼠标坐标同一行固定居中显示“全修正良率”和“不修正良率”，不增加图形上方的高度。狭窄窗口中的导航按钮通过工具栏自带的展开菜单访问，数字不会随坐标文字移动。

- 全修正良率：修复全部未忽略红黄问题，忽略线路保持原图。
- 不修正良率：所有问题都不修正。
- 两项只统计宽度事件，包括通道、封装边距与禁布区；不与异网接触良率混算。
- 输入仍是最大幅度、真实旋转中心、系统均值及XY相关性。0、∞沿用最近有限非零概率尺度，首次6。原接触显示的∞仍是当前姿态二值判定。

令整包姿态向量为 \(z=(z_1,\ldots,z_D)\)，每颗芯片的 \(z_i=(d_{xi},d_{yi},\theta_i)\)。X/Y单位为μm，转角由界面度数乘π/180换算为rad。D是芯片数。H是各芯片输入幅度构成的联合硬边界，\(f_H\) 是盒内归一化的联合正态密度；同一DIE所有图形共享姿态，DIE之间采用既有独立模型。

R、A分别为任意线路出现红色、黄色问题的事件并集，S为忽略的源线路集合：

\[
I(S)=\bigcup_{\ell\in S}(R_\ell\cup A_\ell),\qquad
Y_{\rm 修正}=1-\Pr(I(S)),\qquad
Y_{\rm 原图}=1-\Pr(R\cup A).
\]

增加忽略集合，\(I(S)\) 只能扩大，因此全修正良率单调不增，且不小于不修正良率。两者差值为

\[
\Delta Y=\Pr((R\cup A)\cap I(S)^c).
\]

所有问题都忽略时必相等；共享或包含的失效事件也可能提前相等。因此不能人为按忽略条数线性扣除良率，或强制只在全部忽略后相等。程序独立累计差值质量，悬停数字可查看；有限积分未分辨到差值时会明确说明，不把它当作所有风险均已忽略。

GD55旧默认4096次直接正态采样仅命中一条线路（5/0源编号26），导致忽略后两项估计相同。本版增强尾部覆盖，仍用原概率密度加权，不人为提高尾部风险的发生率。

## 宽度分析的独立数值设置

“设置 → 宽度分析 · 良率计算”包含：

| 参数 | 作用 |
|---|---|
| 计算方法 | 尾部增强采样 / 全情况分析（有限网格穷举） |
| 采样数指数 | \(M=2^e\)，e为8–20，默认12 |
| 采样随机种子 | 默认510，相同输入可复现 |
| 每活动轴网格节点数 | 3–21，默认5，含两端点；仅用于全情况模式 |

“无接触良率计算”继续控制原有无接触模型，与宽度数值设置分开。旧工程缺少新字段时继承原采样数及种子，旧确定性选项迁移为有限网格模式。新设置、输出目录和展开状态随工程保存，schema5不变。修改宽度积分设置不会重建当前几何预览或清除其缓存；忽略集合变更只重分类已存事件。

### 尾部增强

令 \(q_0\) 为按截断X、给定X后的截断Y和独立角度依次生成的条件密度，\(u_i\) 是第i颗活动芯片在硬边界上的均匀密度。A为活动DIE集合、\(D_a=|A|\)。锁零轴不增加维数，完全相关XY使用一维支撑线。

\[
q(z)=\frac12q_0(z)+\frac{1}{4D_a}\sum_{i\in A}u_i(z_i)q_{0,-i}(z_{-i})
      +\frac14\prod_i u_i(z_i),\qquad w_m=\frac{f_H(z_m)}{q(z_m)}.
\]

\(q_{0,-i}\) 为其他DIE条件密度的乘积。先抽取混合分量再生成联合姿态，每个姿态先合并全部线路事件。分子、分母均使用实际密度；程序在对数域计算权重。

\[
\widehat Y_j=\frac{\sum_{m=1}^M w_m\,1_{\{z_m\notin F_j\}}}{\sum_{m=1}^M w_m}.
\]

\(F_{\rm 修正}=I(S)\)，\(F_{\rm 原图}=R\cup A\)。指示函数在对应姿态没有失效时为1。成功、失效和修正收益分别累计，保留小于浮点“1减去概率”精度的尾部。极小失效仍以“100%−科学计数法百分比”显示；小数位数沿用宽度分析显示设置。

对两轴都活动且非退化相关的DIE，令母标准差为幅度/k，标准化X为x，\(\Phi,\phi\)分别是标准正态CDF/PDF：

\[
s_i=\sqrt{1-\rho_i^2},\quad q_X=\Phi(k)-\Phi(-k),\quad
a_i(x)=\Phi((k-\rho_i x)/s_i)-\Phi((-k-\rho_i x)/s_i),\quad
Z_i=\int_{-k}^k\phi(x)a_i(x)\,dx.
\]

k是有限概率尺度，\(\rho_i\)为XY相关系数；其他轴退化情况单独处理。原密度与\(q_0\)的比值为各相关DIE的\(q_X a_i(x)/Z_i\)之积，不能把相关XY当成独立轴。

有限样本区间采用有界加权量的经验Bernstein界，并对两项成功、两项失效、权重总质量和差值共6个统计量的上下两侧联合校正。固定样本数和固定忽略集合下置信度99%；交互选择忽略集合的全部历史查询不具有统一同时保证。具体均值、方差及比值区间公式显示在软件报告中。[Maurer–Pontil 定理4](https://arxiv.org/abs/0907.3740)

### 全情况分析：无随机采样

每颗DIE的每个非零幅度轴，在均值±幅度之间设置n个等距节点，包含端点。相邻节点的中点划分积分区间，首尾截在输入边界。零幅度轴锁为0，不增加组合。另保留不带概率质量的名义零位参考，供几何规则复用。

对DIE i的局部节点r，令对应三维区间为 \(C_{i,r}\)，权重为

\[
w_{i,r}=\int_{C_{i,r}}f_{H_i}(z_i)\,dz_i,\qquad
Y_j^{(n)}=\sum_{r_1,\ldots,r_D}
\left(\prod_i w_{i,r_i}\right)1_{\{(z_{1,r_1},\ldots,z_{D,r_D})\notin F_j\}}.
\]

角度和独立轴用正态CDF差，相关XY用条件正态的一维积分得到区间质量，完全相关情况按支撑线积分。每个DIE的权重归一化。它们不是等概率，也不是把每个节点的PDF直接相加。

程序按两壁、第三方占位及边缘事件的真实依赖计算，使用决策图合并概率，**与逐个计算全部有限网格组合等价**。没有随机抽样，也不暗中跳过剩余组合。进度栏报告等价组合规模及处理阶段。

**这是有限分辨率的离散近似，不是连续空间的有限精确穷举。** 节点数会影响结果，尤其在高σ尾部和几何阈值附近；应增加节点检查收敛。区间质量积分误差不能替代几何离散误差。任意数值预算下都不能声称已经遍历了无限多个连续姿态。

## 视野外标签

已选风险线路移出视野时，箭头指向与该线路最近的视野边缘，文本框仍位于绘图区内，沿用原来的颜色、边框和箭头。平移、缩放、重新入镜及多选会实时更新。当前姿态的显式选中线路及宽度表所选区段同样处理。图外独立文本框已经移除。

优先避免窄口和其他标签；空间实在不足时仍将显式标签保留在图内。单个标签大于绘图区时适当缩小以适配，不改变保存的字号偏好。大量标签同时显示时仍可能相互遮挡，可减少选集或扩大绘图区。

## DXF输出

左侧“输出 → DXF输出”使用系统保存对话框，Windows不使用自定义窗口样式。选择路径后在后台写出，进度和错误进入运行信息。导出包含：

- 软件已经导入的全部二维几何，隐藏及不参与图层也保留。
- 工程Q节点修改与当前已完成姿态的移动、旋转。
- 已启用的型变／重构替换几何和直线修复补块。
- 原始孔洞、直线节点，图层命名为L层号_D类型，单位μm。

选择导出时停止插值动画，使用当前已完成的几何帧。只输出实际几何，不输出热图、风险矩形、虚线范围、选中描边、参考原位影子或良率假设。导入时已经忽略的无效几何不参与输出，日志说明数量；没有声称导出未进入软件几何模型的原始GDS文字或其他顶层Cell。

参考File Bridge 1.16.2的AC1015数据库结构、句柄／所有者关系、ASCII+CRLF和微米单位设置。普通轮廓输出闭合LWPOLYLINE；含孔洞图形使用直边HATCH环，保留孔洞。**不使用多段线圆弧恢复、拟合、简化或新增ARC/CIRCLE。** DXF写出只使用现有Python几何和标准库，不需要KLayout安装位置，也没有打入整个KLayout软件。

先写同目录临时文件，核对记录和实体完整性后原子替换目标。失败或提交前取消保留旧文件。使用KLayout回读闭合多段线的面积时需选择“闭合零宽多段线转多边形”；CAD中的轮廓本身保持不变。参考来源和验证见协作记录。
