# V48 操作说明

V48在V47预演软件基础上增加RealDataAnalyse计划队列、实时IPC会话和项目输出整理；两软件始终同包同版本。预演算法、GD55控制柄及按需实测冻结保持[V47说明](V47_使用说明.md)的合同。

## 常规任务

选择Jobs中的项目文件夹，勾选各DIE的Excel并核对列映射。共用映射默认开启；关闭后点Excel行切换独立映射。点击“创建任务”完成校验、按封装ID匹配并保存记录，再“运行 / 继续补算”。记录表每500ms自动更新当前200行，每行展示各DIE的dx、dy、角度及可选中心；长内容可双击展开。所有表格仅用左侧行标题显示行号，表格下缘双线可拖动改变高度。

任务超时默认0，即不限制计算等待时间；本地连接/认证仍有独立的有限超时和有界重试。底部进度按真实阶段/回执更新，左侧无文字checkbox显示或隐藏详细信息。

## 计划任务

调整当前项目、Excel勾选、映射、线程等参数后，点击“创建计划任务”，保存独立设置快照。可切换项目继续添加。连接区域“启动预演软件”右侧“计划任务”打开独立面板，点“开启计划任务”按行顺序执行，每个计划内部按自己的并发线程计算。每行显示状态、进度、开始/结束时间，完成浅绿、缺失输入或不可运行浅红、输出冲突浅黄。

同项目计划共用一个最终OAS，黄色提醒仍会按顺序执行；新结果成功后，旧结果归档到Cache，历史计划结果路径同步指向归档。输入文件创建计划后若变化，执行前摘要核验将拒绝该行，应重新创建计划。计划状态保存在安装目录Jobs/.RealDataAnalyse/plans.sqlite，任务持久记录在项目Tasks/Plans，工程/图纸快照位于项目Cache。安全停止保留未完成项；再次开启继续待执行项，不重复已完成项。失败项需在面板重试；无法安全确认实例退出时停止后续队列并保留日志。

## 输出和缓存

项目Output成功后只保留一个最终结果OAS。批次OAS、partial文件、锁和导入/工程暂存放在Cache；旧Output附属文件移入Cache/History，不直接删除。先核对完整数量、CRC及SHA-256，再原子提交。失败或停止不清理旧输出。输入图纸、Excel或任务库不允许放在Output后再进行整理，避免移动输入。Tasks是持久任务记录、logs是实时日志，均在项目内。

## 实例与实时命令

只启动当前安装目录的预演软件；实例按工程绝对路径、IPC实例ID和进程身份匹配。不会为了选择另一项目而自动切换其他窗口的工程。同一工程多个实例且未明确选择时提示选择入口。计划使用各自专用入口，自动启动的实例在本项完成后安全退出；借用的用户实例保留。

“实时命令信息”位于全部IPC命令调试右侧，显示实际请求、回复、异常与进程管理信息。界面默认保留2000行，可设置100–10000；后台队列及单条显示长度也有上限。完整报文脱敏后记录到项目logs/IPC-conversation.log，16MiB轮转、最多5份。界面省略时有提示；本地协议采用请求/响应与task.get轮询，没有独立推送通道。

## 构建与边界

根BUILD.bat构建相邻两个无控制台EXE；RealDataAnalyse另有RUN/BUILD。正式发布联合源码ZIP与SHA，随包Jobs/GD55三份合成Excel及授权图纸，EXE只用于Windows验收。自动化保留--import-data/--run，新增--run-plans plans.sqlite。批量输出仍跳过完整DRC/概率，合成案例和托管Windows检查不等于工厂数据或物理GPU验收。
