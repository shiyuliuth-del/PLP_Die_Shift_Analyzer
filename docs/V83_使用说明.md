# V83 端点随动控制、未打包免鉴权、限时授权、按 DIE 动区间菜单与多分支重构

- **固定过孔上固定 RDL 防误判与端点区间独立控制**：
  - 修复 `ignored_motion` 与 `DIE 内动区判断` 在端孔网络号不直接相等时遗漏固定过孔的问题，连接固定过孔的固定 RDL 在极限工况下保持静止，不会误判为整块随动。
  - 支持左键单独选中靠近固定过孔及靠近运动过孔的刚性端点铜区（不仅限于动区之间的区间）；在同一位置再次左键单击可循环切换为选中整个图形，再次点击回到子区域。
  - 右键菜单新增「端点随动：随动 / 静止」（默认随各自过孔状态，可强制覆盖并按实际状态参与姿态铜形生成与 ABC DXF 归类）。
- **默认正态标准差**：`X偏移标准差 = 3.0 μm`、`Y偏移标准差 = 3.0 μm`、`角度标准差 = 0.02°`。
- **源码免鉴权与独立 EXE 运行**：未打包为 `.exe` 时（源码模式）跳过授权校验；仅在打包后的 `.exe` 中校验离线授权。双击 `Die_Shift_Analyze.exe`、`RealDataAnalyse.exe`、`LicenseManager.exe` 时不依赖同级目录下的 `.bat` 启动脚本。
- **限时授权支持**：`LicenseManager` 新增「授权时长（月）」参数（默认 `0` 表示无期限永久授权；`> 0` 按自然月计算到期时间并在签名载荷中校验）。
- **动区间右键菜单与滚动优化**：
  - 在「静止不动」下方按芯片顺序提供「跟随DIE1移动」「跟随DIE2移动」……（导出 ABC DXF 时统一归入 `_A`）。
  - 将「跟随幅度大的一侧」「跟随幅度小的一侧」「两侧平均」归类放入「特殊随动跟随」子菜单。
  - 当右键菜单高度超过屏幕可用高度时自动缩小并支持菜单内鼠标滚轮滚动。
- **多分支自由创建与框选动区**：修复在多分支图形上于一个分支及主干创建动区后无法继续在其他分支通过「增加动区」或框选创建动区的问题。
