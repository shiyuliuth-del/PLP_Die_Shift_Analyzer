# V58 使用说明

RealDataAnalyse 与 Die Shift Analyze 同包发布。生产导入使用项目里的 `RealDataAnalyse/Excel/`。每颗芯片建立一个直接子目录，目录名即芯片名。每个目录放一份或多份测量 CSV 或 XLSX。选择项目后，客户端列出文件，并从目录数量显示芯片数量。已保存的旧式 `Measurements` 工作簿仍可按封装 ID 导入。

生产表头为 `行`、`列`、`是否成功`、`理论坐标X`、`理论坐标Y`、`实际坐标X`、`实际坐标Y`、`偏移X`、`偏移Y`、`旋转角度`。CSV 支持 UTF-8 和 GB18030。坐标按毫米转为 μm，角度按度读取。以芯片中心为旋转中心，使用实际坐标定位。原表偏移值保存在任务明细中供核对。

同一行列号可在多个区域重复。对每颗芯片，用全局理论中心减去工程内相对于封装左下角的名义中心来求封装锚点，并用这些锚点匹配同一封装。程序通过理论位置匹配芯片目录与工程 DIE。每个封装取匹配锚点的均值，芯片平移由实际中心反算。默认匹配容差为 2 μm。若机器使用 μm 或芯片目录与图形的对应存在歧义，可在 `RealDataAnalyse.project.json` 的 `measurement` 内指定 `scale_um`（μm 时为 1）、`match_tolerance_um` 或按工程 DIE 顺序的 `die_order`。一个封装内有 `是否成功=0` 时跳过该封装并记入日志，重复或无法唯一匹配的数据须修正后重新建任务。输入文件只读。

线程与内存的默认值 0 由软件根据系统资源和工程复杂度选取，工程里已有的明确值继续生效。进度条在结束后保留开始、结束和累计耗时。完成的普通任务弹窗显示输出路径，计划队列在表内报告状态。

OAS 的 `ERROR` 层标注普通尺寸和间距 DRC，`ERROR2` 层标注连接失败、开路和短路等严重问题，`FAIL` 层保留发生彻底连接失败的封装边框。前两层在对应 DIE Cell 内以贴合当前问题区域最小外包方向的四边 Polygon 表示。诊断计数按层写入回执和日志，最终 OAS 保存到 `RealDataAnalyse/Output/`。

`Jobs/SH22` 提供 4 个区域、400 个封装、两颗芯片、每颗两份 CSV，共 800 行合成测量。包含零位、常规小偏移、较大偏移及旋转压力姿态。案例的尺寸容差为 0.5 μm，最小图形面积为 1 μm²。在 RealDataAnalyse 中选择 `Jobs/SH22`，创建任务后运行。生产批次耗时取决于工程复杂度与具体偏移。

发布入口仍为 `RUN.bat` 和 `BUILD.bat`。其他预演交互见 [V57 使用说明](V57_使用说明.md)。
