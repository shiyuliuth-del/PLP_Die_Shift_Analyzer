# Die Shift Analyze V74

## 动区间随动

重构预演中，直接右键单击两处动区之间的铜段即可选择「跟随幅度大的一侧」「跟随幅度小的一侧」或「两侧平均」。短段即使靠近两个边界，也可以从铜段内部打开随动菜单。右键点在边界线上可继续操作边界。

关闭自动计算后，局部草稿会更新。点击「重构计算」后统一应用并重新核验。显式切换策略随工程保存。与真实端孔或已有刚性归属接缝相连的铜段会说明约束。无法应用的名义锚点、缺少截面和分支冲突写入「运行信息」。计算异常导致操作无法完成时，软件恢复该操作之前的设置、已显示结果和撤销记录，并弹出简短提示。

## 动静区 DXF

以名义铜的同一条实体轮廓生成分段多段线。分区与源轮廓相交处若受浮点舍入影响，将接缝端点恢复到同一源边上。正补偿后，真实分区接缝延伸至扩展的实体边界。输出仍使用 `_A` 表示随动侧、`_B` 表示静止侧、`_C` 表示动区。

SH22 回归在（−241967，245577）附近手动框选，并逐截面回读 0、+1.5 和 −1.5 μm 补偿的 DXF，核对两条外边的标签和外轮廓闭合。另有 Qt 回归覆盖短段菜单的「两侧平均」以及后台事故的回撤。由于分支净距、端孔约束和可用空间各不相同，出现真实重构冲突时仍需要参考当前姿态的核验记录。
