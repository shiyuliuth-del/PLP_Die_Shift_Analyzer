# Die Shift Analyze V75

## 串联动区

软件根据两端的实际运动和各中间铜段的随动策略判断哪些边界同动。两端作同一刚体运动时，该动区不产生相对型变。其余动区均分路径两端的相对位移和转角。分叉按相连材料分别计算，真实端孔和静止归属接缝仍参与约束。

## 联动编辑

一次框选多条线路后，拖动其中一条绑定边界时，其他线路的对应边界同步显示。右键选择「拆分绑定动区」，之后可分别拖动。拆分记录随工程保存，也可撤销。

关闭自动计算时，拖动与合并仍会更新局部草稿。两区合并后，下一次拖动以新的外侧边界为起点，保留已设置的边界角度。点击「重构计算」后统一应用并核验。

## SH22 回归

- （−241037，246512）的自动边界定位到完整截面，长度约 118.68 μm。
- （−242643，246126）附近框选后，跨芯片归属接缝的静止铜段可以单独点选，随动继续遵循实际连接约束。
