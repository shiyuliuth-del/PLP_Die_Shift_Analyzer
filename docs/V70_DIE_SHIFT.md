# V70 主程序

- 层叠表「显示」和「选中」单击切换。用「层 / 类型」列拖动行序。
- 「运行信息」收起时保留后台记录。展开后分批刷新。实测模式停用界面和运行日志写入，指令回执、DRC 数据和实测任务状态照常提供。
- 重构预演中选中图形后右键「忽略选中图形的DRC」。此选择随工程保存，应用于该图形在各姿态的 DRC。右键「取消忽略DRC」会恢复该图形相关问题，含曾被自动忽略的项。电连接失败及实际异网短接仍单独保留，原始规则结果和实测输出继续采用实际几何。
- 「拖动吸附」同时控制轮廓节点及拐角。输入 −1 关闭，0 取当前视图约 5 像素对应的距离。其他正数为 μm。旧工程保留已设置的节点距离，节点值为 0 时采用原拐角值。

## 动静区输入

打开对应原始 GDS/OAS，确认待导入层为固定 RDL。点击「输出 → DXF → 动静区输入」并选择 DXF。识别 `L层号_D数据类型_A` 为运动侧，`_B` 为固定侧，`_C` 为动区。导入以名义零偏移坐标重建可编辑边界，作为一次工程编辑，可撤销和保存。原始图纸保持只读。

V70 导出的 DXF 带有可选工程注释，导入时对照该图纸重建并核验实际轮廓。旧版或经过外部保存的平面 ASCII DXF 可由直线轮廓恢复可唯一对应的分界。缺少可识别切口、无法对应源铜、跨层或多分支外轮廓不足以判定内部边界时，会报告位置并保留当前分区。DXF 本身无法提供原工程的运动过孔及 DIE 端口关系。

## 良率与性能

修复 Windows 重构良率中的内存预算整数溢出。跨芯片图形的局部姿态可拆批并行，所有实际铜仍进入原有联合核验。双 DIE 单铜 729 姿态样例的局部几何阶段由 20.37 秒降至 10.60 秒，规范化输出的 SHA-256 一致。整包耗时取决于图形拓扑与计算范围。
