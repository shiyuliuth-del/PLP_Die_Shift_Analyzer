# Die Shift Analyze V77

动区间设为「静止不动」后，铜段填充比「跟随幅度小的一侧」更深，内部叠加稀疏的灰色菱形点阵。点阵随图层显示。动静区 DXF 将该段对应的铜轮廓输出到固定过孔侧的 `_B` 层，图层补偿后仍保留这个归属。

重构预演中的「固定过孔随动」提供「关闭」「全局随动」「全局静止」「分别处理」。全局随动将整块随动固定 RDL 的名义相连固定孔一起移动。全局静止使所有固定过孔保持名义位置。分别处理沿用逐孔设置。旧工程的「全局模式」打开后对应「全局随动」，旧工程其余选项继续按保存值应用。

专项验收覆盖图形填充与点阵裁剪、正负补偿后的 DXF 归属、固定过孔位置及导出和旧工程设置恢复。
