# Die Shift Analyze V53

## 重构预演

- 预演画面使用通过电连接核验的固定 RDL 铜形绘制底图。动区着色叠在该铜形上，运动端和固定端沿用原图层颜色。连接失败时保留已生成的铜，并在局部显示断口和诊断标记。
- 开启「实时反馈动区变化」后，关闭「自动计算」仍可实时拖动、旋转及在边界线与圆点间切换。局部草稿可在松手后补画。使用「重构计算」一次应用待处理编辑；切换极端情况仍按已应用设置计算新姿态。
- 当前姿态按实际动区判级。浅红表示无法保持连接，浅黄表示连接成立但动区有 DRC 违例，浅绿表示通过，浅灰表示待核验。首行汇总「极端组合」「重点组合」或「全部组合」中当前选定范围的最严重结果，先连线失败，再 DRC 违例，最后通过。
- 「显示 DRC 问题」控制全层问题见证。切换表格筛选时，若当前姿态被过滤，画布保留该姿态，直到主动切换或复原。

## 工程与交付

工程设置仍兼容原有格式。旧版本的结果侧车按版本校验，打开旧工程后可重新生成结果。V53 与 RealDataAnalyse 同包，通过 RUN.bat 运行，通过 BUILD.bat 在 Windows 环境打包。
