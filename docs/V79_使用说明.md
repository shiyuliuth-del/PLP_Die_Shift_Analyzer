# Die Shift Analyze V79

## 永久离线授权

首次启动时复制激活窗口中的一行 Machine ID 发给管理员。管理员返回 `.lic` 后点击「导入许可证」，成功后自动打开主界面。以后每次启动验证本机硬件信息和许可证签名。Windows 授权保存在 `%LOCALAPPDATA%\DieShiftAnalyze\License\license.lic`，移动程序和沿用同一公钥的更新可继续使用。授权信息与替换入口在「设置 → 授权管理」。

[管理员签发与 Windows 构建](../LicenseManager/README.md)。正式私钥和通用许可由管理员首次部署生成。

## 图纸和工程

- 拖动左侧设置和结果之间的分隔线可重新分配宽度。缩窄的一侧可滚动访问。
- 「动静区输入」可从空白窗口打开 DXF，或替换当前图纸。它按 DXF 层名和实体重建图层，保留有编号的层，给其他层自动编号。支持常用二维轮廓及 CAD 块。ABC 轮廓可随工程保存。只有图纸含可追溯的端孔时才可恢复可计算的重构区。
- 工程下拉框第一项会关闭当前图纸，恢复默认参数。工程切换后释放旧引擎与画布几何，已缓存的完整帧可从盘上复用。
- 「重构预演 → 两侧运动的动区生成数量」默认为 1，可设 0–3。0 关闭此类自动生成。三区需有足够可分割的铜段。
