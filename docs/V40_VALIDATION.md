- `gui_v39.py` 的旧左键 QMenu 断言改为本轮明确要求的画布标注，仍用真实按下/释放事件。V29 的程序化筛选入口改核实际重构规则，历史直线包络辅助函数的独立单元保留。

## GD55 与性能范围

[实图记录](../results/v40_gd55.json)与[独立轮廓/角度记录](../results/v40_layout_checks.json)的运行摘要均与上述功能头相同。

- 19,683个离散组合全部以依赖因子检查；实际构造17,174个局部几何，检查23,162个兼容且空间可接近的异网组合。抽取12个完整姿态逐动区、逐筛选标志与全场原生规则核对一致，包含仅第三颗DIE转动的姿态，修复了无关DIE改变共享铜量化分支的问题。
- 143条重构记录的首行汇总为115条风险、28条全离散通过；它是规则记录数量，**不是良率或成功适配率**。原图自身规则问题使本工艺下全部组合都存在问题，筛选保留19,683行（含零位）是实际结果。无可信分区仍保留原图并警示。
- 首次规划及名义帧另次观测266.93 s；最终全组合复算复用同一规划模块生成的本机路径快照，初帧1.75 s，不能称为冷启动。全离散检查722.48 s；路径/局部缓存已热后的完整姿态首遍1.51–2.43 s，均非端到端FPS。8逻辑CPU/约15.3 GiB内存，CPU计算，期间还有回归负载，不能拿不同轮次当严格速度对比。
- 共享DIE先联接避免不可能的状态比较；本机原生后端串行，规则前端上限2线程，几何支撑域缓存避免重复并集/缓冲。完整帧及相同设置的检查继续复用；冷计算仍有明显耗时，未宣称所有操作实时。
- 在同一完整混合姿态，重构区优先/两侧平均分别有76/18条记录调整截面方向，全部保持共用端点并输出有效几何；仍有56/55组规则违规，均保留标记。首次模式帧23.42/17.25 s，不能将几何有效冒称DRC通过。
- 完成帧的ABC导出3.37 s；2,506条LWPOLYLINE全部开放，共同端点零遗漏，无HATCH。逐层与实际铜边界对照最大Hausdorff距离5.69×10⁻¹⁴ μm，最大周长差3.50×10⁻¹⁰ μm。另有合成逐折线串并行等价与失败保留文件测试。

## 边界

绿色是全离散通过；一般连续风险仍未知，灰色只能由充分上界证明。角度/连接搜索有限，不能保证所有有空间的任意形状都找到解。整包重构模型只含所列几何规则，不代表实测制造良率。首次规划和全极端可能较慢；缓存命中、几何单步耗时与端到端帧率分别解释。

Windows 托管机与 Linux 本机验收不替代工厂 Windows 镜像、实际 CUDA 硬件和生产 DRC。源码 ZIP 不含图片、图纸或 EXE。
