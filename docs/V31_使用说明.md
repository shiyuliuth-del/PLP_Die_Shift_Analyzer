# Die Shift Analyze V31

## 在另一台 Windows 电脑一键打包

1. 下载 `Die_Shift_Analyze_V31_Source.zip`，完整解压到可写目录。
2. 在解压目录中双击 **BUILD.bat**。打包机需要已有 Python 及 `requirements.txt` 所列依赖，其中包括 PyInstaller。脚本不固定版本，也不会联网安装包。已有环境未在 PATH 中时，可用 `DIE_SHIFT_PYTHON` 指定其 `python.exe`。
3. 等窗口显示 `Ready`，在 `dist` 文件夹找到生成的 `Die_Shift_Analyze.exe`。将这个文件复制到可写目录，首次运行会在它旁边创建 `Jobs` 和 `logs`，并保留原有工程。

**RUN.bat** 是直接运行源码的入口。**BUILD.bat** 只负责打包。两个脚本共用同一套解释器选择逻辑，已有使用 `RUN.bat build` 的调用也可以继续使用。源码文件夹路径可以含中文和空格。

应用图标由源码绘制，在目标电脑的打包过程中生成并嵌入 EXE。默认完整依赖清单包括 KLayout Python 模块；仅使用已安装的 KLayout 桌面后端打包时，生成的程序在目标设备上也需要可发现的 KLayout 桌面程序。

## 交付内容

正式 ZIP 包含运行源码、两个 BAT、依赖清单和 PyInstaller 构建规范。SHA-256 随 ZIP 单独提供。开发文档、测试和示例在完整 Git 检出中查看。
