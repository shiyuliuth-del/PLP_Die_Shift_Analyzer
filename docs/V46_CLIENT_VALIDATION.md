# V46 RealDataAnalyse 客户端验收

## 最终界面合同

- 仅选择项目文件夹，工程自动推断；工程、任务记录和最终OAS三行输入删除。任务/OAS默认在项目的Tasks/Output内，日志在logs内。
- Excel选择为勾选表格，支持添加/删除行；删除行不删除文件。列映射为表格，左侧checkbox默认共用。取消后点击Excel行切换该文件自己的工作表、表头行和列名；切回共用保留独立配置。
- DIE数量、线程、内存、重试、超时位于连接与工程栏目底部。连接状态/启动预演软件按钮以红绿反馈。
- 底部为无文字的信息checkbox和连续进度条；信息输出默认隐藏。进度文字与色带在同一绘制坐标中，长文本省略并提供tooltip。
- 移除重复品牌/说明标签与生成GD55示例按钮。随包案例为Jobs/GD55；BUILD复制到dist/Jobs/GD55，已有项目不覆盖。两个GUI EXE同目录，源码RUN使用pythonw。
