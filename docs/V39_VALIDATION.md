# V39 验证记录

起始主线 `fe6e3b0de264a445d2fb409d5184befca8317d3f`，任务分支 `codex/v39-connection-styles`。本轮增加连接样式、拖动绘制修复、规则反馈和全输入重构良率，并审查 GD55 指定位置。最终聚合与 Windows 记录在发布前补齐。

## 可复算检查

- `tests/test_v39.py`：四交点直线、圆弧切向与圆半径、整孔盘不塌缩、工程兼容及缓存键、三类规则见证、整包网格与逐姿态全几何检查、两颗独立 DIE 的联合事件、原生布尔与标记结果对照、极短过渡节点预算、∞参考尺度、背景残影逐像素对照。
- `tests/gui_v39.py`：真实 Qt／Matplotlib 拖动，四样式切换，点柄悬停与拖动持续动画，实时反馈开关，工程还原，后台约束与固定位置良率。
- `tools/benchmark_v39.py --gds <GD55路径>`：只读实图、8个 ±35 μm/±1° 叠加工况、默认15/15/15 μm规则、共享端点、绘制分区与实际铜一致性、完整有限网格良率和分项耗时。
- 聚合验收入口 `python3 tools/package_release.py verify-source`；Windows clean／with-cupy 均以最终功能头验证。Linux及合成测试不替代Windows或实际显卡验收。

## 已知边界

自动局部概率排序采用名义邻网和有限候选；全输入包络及最终联合规则结果单独报告。手动端点保留，可能存在规则冲突，此时标记而非冒充合格铜。GD55的多分支/多DIE共享铜仍可能保留源图；几何有效不代表完整DRC通过。

指定坐标在V38数值复算中未发现铜形丢失，属于共享源图形。修复了共享静区按源索引仅保留第一份的显示漏洞；不能以数值复算替代用户原窗口状态的完全重现。最终保留绘制覆盖回归证据。

开发诊断中，Python3.12 的 `faulthandler.dump_traceback_later` 后台转储线程曾发生崩溃，原生栈位于 `_Py_DumpTracebackThreads`；未作为程序功能回归结论。该临时诊断代码不在应用中，正式复算不使用此转储线程。
