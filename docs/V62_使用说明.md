# V62 使用说明

## Windows 启动与打包

- 用 `DieShiftAnalyze_RUN.bat` 启动 Die Shift Analyze。
- 用 `RealDataAnalyze_RUN.bat` 启动 RealDataAnalyse。
- 根目录的 `BUILD.bat` 用现有 Python 环境构建两个单文件 EXE，并把两份启动脚本复制到 `dist`。

两份脚本优先查找同目录及 `dist` 内的 EXE。找到 EXE 后，可以在没有 Python 源码或解释器的电脑上使用。源码启动可用 `DIE_SHIFT_PYTHON` 指定已有解释器。

## 工程与界面

首次保存工程会建立项目内的 `RealDataAnalyse` 工作区及 Excel、Template、Output、Tasks、Cache 和 logs 等目录。默认框选动区遵循「边界角度」，显式保存为「自由」的旧工程继续按原设置打开。接触标记选项与 DRC 类别合并在「设置 → DRC」。固定过孔右键菜单移除「增加动区」，运动过孔仍可在其实际连接的固定 RDL 上添加动区。

## 动静区 DXF

封装边框层名改为 `PKG_REF`，芯片边框为 `DIE_REF`。固定 RDL 的 `_A`、`_B`、`_C` 分别表示运动侧、固定侧和动区。每个源图形在同一输出层仍使用一个 CAD 块，块内可连续连接的轮廓合成多段线。整圈位于一层时输出一条闭合多段线，跨层分界保留一致的端点。
