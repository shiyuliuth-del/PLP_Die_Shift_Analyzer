# V71 使用说明

## 框选动区叠加与扩展

- 单个固定 RDL 图形支持任意数量的动区。使用「框选动区」时不再删除该图形上原有的其他动区：
  - 若新选框与已有动区不相交，在原有基础上新增独立动区；
  - 若新选框与已有动区重叠，则将原动区范围扩展为两者的并集范围，其他未重叠动区保持不变。
- 自动规划在同一条线段区间上仍最多生成两个动区，允许用户通过手动「增加动区」或「框选动区」创建任意数量。

## 固定过孔随动逻辑与动区间随动逻辑

- 重构预演参数中，原「整块随动联动固定过孔」更名为「固定过孔随动逻辑」，并在其右侧新增「动区间随动逻辑」下拉框：
  - 可选项：`跟随幅度大的一侧`（默认）、`跟随幅度小的一侧`、`两侧平均`；
  - `两侧平均` 表示多个动区之间的刚性铜段按两侧实际运动的平均幅度和平均转角作整体刚体随动（两侧均运动或一侧运动一侧静止均按同一平均逻辑计算）。
- 「动区间随动逻辑」设置的是全局默认状态。当一个图形存在多个动区时，可在画布中直接左键单独选中动区之间的铜段，并通过右键菜单单独切换该段的 `跟随幅度大的一侧`、`跟随幅度小的一侧`、`两侧平均`（或恢复默认），并随工程保存与撤销。

## 动静区输入自动同步层叠状态

- 使用「输出 → DXF → 动静区输入」时，不再因软件当前层叠设置与 DXF 不一致而报错。读取 DXF 后自动将软件的图层用途、层序与输出补偿更新为 DXF 中的层叠状态（无注释的外部/旧版 DXF 也会自动将 DXF 中包含 `_A`/`_B`/`_C` 轮廓的图层设为 `固定RDL`）。

## 层叠表格右键修改颜色样式

- 保持层叠表格当前的左键选择与行拖动行为，改用**右键单击**对应行弹出该图层的颜色、透明度、填充与描边样式修改弹窗。

## 大规模图纸性能优化

- 向量化 `stack.Connections.resolve_ownership` 的芯片归属与过孔包含查询并避免单图形冗余合并（12,000 图形构建提速约 3.2×）；
- 缓存 `RoutePlan.moving_line_partition`、提高路径缓存容量并前置 `covers` 判断跳过冗余布尔求交；
- 为动静区 DXF 输入 `region_import.assign` 预处理轮廓缓冲区，提升大规模图纸导入与划分流畅度。

其他常规与 RealDataAnalyse 客户端用法参见 [V70 使用说明](V70_使用说明.md) 与 [V70 主程序](V70_DIE_SHIFT.md)。
