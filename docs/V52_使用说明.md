# Die Shift Analyze V52

新图纸默认选用「极端组合」。现有工程若保存了「重点组合」或「全部组合」，打开时恢复其设置。极端目录保留零位、各 DIE 最小间距及最大位移见证、DIE 对的最靠近及最远离姿态，以及各 DIE 局部风险较高的联合姿态。筛选会去重，零幅度的轴保持为零。

「极端组合良率」是选中代表单元内的条件概率。每个姿态的权重取其对应的有界正态单元质量，再除以全部入选单元的质量。重点组合沿用相同的条件化口径。全部组合仍可执行完整目录检查。结果分析页的连续安全盒与连续无接触模型使用整段输入范围，和重构/宽度的组合良率承担不同用途。

在「通用」设置「表格每页最大行数」，极端表和 DRC 表即时刷新。默认 500，极端表的零位首行也计入此限额。「最大并行数」使用工程原有的资源上限字段，0 按硬件自动选取。原生几何、核验线程和实测进程按任务需要分配。

「工艺 → 其他 → 最短边长」默认 0.01 μm，0 关闭。缩短时删除短边的一端并连接相邻点，轮廓和孔洞均处理。退化轮廓会删除，无法得到有效轮廓的图形会记录在运行信息中。过滤在原图的工程副本上执行。当前姿态导出会过滤型变后生成的短边，保留独立诊断层和动静区 DXF 的公共接点。

框选动区使用四向指针，按住左键可用滚轮调整框角度。原框可以形成有效切口时使用原框。如果框陷在铜内部，先在本条线路横向扩展，必要时再局部沿线扩展，仍保留原选区。无法生成有效边界时保留诊断。

「重构预演 → DIE内动区判断」可选「自动」「DIE内随动」「DIE内静止」，默认为随动。该策略作用在完全落入单颗 DIE 边框的固定 RDL，含孤立金属。手动指定的动区和忽略模式优先，且两种整块模式都按实际位置继续检查连接和 DRC。自动项按包围量与周围空间选择。
