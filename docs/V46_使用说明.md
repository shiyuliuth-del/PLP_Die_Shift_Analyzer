# V46 开发与验收中

本轮修正折叠样式、区域编辑与边界拖动；Jobs改为每项目文件夹，图纸副本与相对路径工程放在一起，结果侧车位于Cache。旧平铺工程可读，保存时迁移并保留原文件。

实测批次在首个封装、每64个完成封装和内存阶段写出可独立打开的批次专属.partial.oas；结束仍原子提交最终OAS。阶段文件保留供恢复，不表示所有请求都已完成。

复杂多孔图形比较经完整输入盒证明的整体静止/随动候选，不能证明时继续局部适配。最终电连接与规则检查保留。

RealDataAnalyse只需选择项目文件夹；工程路径自动推断，任务记录和最终OAS默认在该项目的Tasks/Output内。Excel选择改为可勾选表格，列映射也以表格编辑，删除行不删除文件。连接/启动按钮位于栏目底部并显示绿/红状态；信息输出默认隐藏，可用checkbox展开；连续进度条在最底部叠加真实阶段、计数、百分比和用时。源码RUN用pythonw，EXE无控制台。

随包案例位于Jobs/GD55；选中文件夹后自动读入三份合成Excel并联动预演工程。构建后案例复制到dist/Jobs/GD55，已有项目不覆盖。Excel选择/映射/内容变化须重新创建任务，项目迁移后不复用旧路径的任务回执。更多操作见[客户端说明](../RealDataAnalyse/README.md)。
