# V82 正态标准差参数、授权目录、加载保存性能与重构边界修复

- **系统偏差与相关性新增正态分布标准差**：在「工艺 → 系统偏差与相关性」中新增 `X偏移正态分布标准差`（默认 `3.0 μm`）、`Y偏移正态分布标准差`（默认 `3.0 μm`）和 `角度正态分布标准差`（默认 `0.02°`），系统偏差均值默认仍为 `0`。支持全局统一与「逐 DIE 标准差」两种模式，所有概率算法（接触概率、极值概率叠加、通道宽度概率/采样/良率、重构区间与联合模型良率）统一按所配置的正态分布标准差计算。
- **LicenseManager 默认目录调整为 EXE 所在目录**：`LicenseManager` 的工作数据目录（签发历史数据库）、密钥默认目录（`keys/`）、签发输出目录（`licenses/`）及通用许可目录均默认位于 `LicenseManager.exe` 同目录；`BUILD.bat` 同时支持自动查找 `dist_admin\keys\public_key.pem` 与 `dist_admin\public_key.pem`。
- **界面与性能改进**：
  - 「设置 → 重构预演」中的 `两侧运动的动区生成数量` 更名为 `两侧运动动区数量`。
  - 优化图纸加载、多边形编译缓存与层叠连接查询速度，后台预解码 `.dsresults` 侧车结果；保存工程（`save_project`）时显示实时进度条。
- **重构算法与交互修复**：
  - 修复双侧均生成动区（`两侧运动动区数量` 切换后）时中间刚性铜段未能随设置刷新而被增量缓存复用、导致无法单独选中并设置随动状态的问题，并清理多动区中间核中的零面积碎片。
  - 修复多端孔（如一对多/多对多/近端与拐角并存）重构优先级与分叉窄缝截断问题；当两个以上运动过孔和两个以上固定过孔分别在两侧聚集在一起时，仅在中间连接线上生成一个动区，且其边界仅受离它最近的过孔制约。
