# 已知边界与后续重点

V45已发布，最终Windows双环境与源包验收完成；记录见[V45验证](V45_VALIDATION.md)。全层DRC覆盖范围扩大，首次规则扫描可能比旧接口窗口检查耗时；未完成时显示检查中，不复用错误姿态坐标。尺寸容差不放宽包围量。原图规则不合格可使重构模型良率为0，不能当作电连接适配率。

V44联合验收见[V44验证](V44_VALIDATION.md)及[全部离散电连接记录](V44_CONTINUITY.json)。V43历史验收见[V43验证](V43_VALIDATION.md)。上一版实图基线见[V42验证](V42_VALIDATION.md)与[详细数据](V42_cases.json)，不能直接当V43实测输出的最终验收。历史问题在对应Git标签保留。

- 三个实图的全部需要追溯接口已覆盖，但部分极端仍有规则失败、折叠或连接候选失败。不得把覆盖率、几何有效或绿色区域当成生产良率。
- 多端合并域采用连续位移场；圆弧选项在多端域使用C1权重，不是任意多端精确圆弧。复杂回路、多DIE共网、窄区域仍可能需要人工调节或后续候选优化；最终仍不可行时拒绝新结果并保留上一完成状态；内部诊断候选不作为输出。
- 有限离散/网格不等于连续空间穷尽；灰色必须有充分概率上界，未知仍保留风险。
- 首次规划、新的强制/工艺配置和完整统计仍可耗时；局部拖动与缓存优化不构成整体速度或30 FPS保证。后续优先缓存跨DIE组合内重复的分支组装，再以相同几何/规则测量独立原生进程收益。
- 旧通用ABC后端遇到极小退化边会拒绝偏移铜输出并保留旧文件。V42产品入口固定输出名义零位，三个实图文件均通过闭合/重复/重合检查。
- 结果侧车需与工程一起保留；缺失、损坏、版本/几何/参数变化、未完成时恢复设置并重算。跨盘引用为绝对路径，换电脑可能需重算；持久快照与运行缓存清理不同。
- Windows托管验证不替代工厂离线镜像或物理GPU验收。保留CPU回退，本轮没有GPU提速证据。V41曾有一次未重现Linux退出异常，检查器继续按退出码和错误日志判定失败。

- V43实测批量明确跳过完整DRC/概率，仅执行几何求解与连接检查；正常生产导出不得忽略失败回执。增量内存预算非操作系统硬隔离。当前输入/输出以物理多边形为主，不保留原GDS/OAS文字、属性和命名层级。接口详细边界见MEASURED_OUTPUT_API。
- nul7123（附件名nu17123）指定（7379,2933）的长单向死区在提供的保存状态/偏移探查中尚未完整复现。已修正倾斜柄点击位置引入的弧长偏置；邻近真实柄向下2/5/10μm均正确运动。不能据此宣称用户原工况已逐步复现；后续优先取得具体姿态和边界设置复查。

- V44 RealDataAnalyse的产线Excel模板尚未提供；当前.xlsx列映射和GD55合成例不代表任意Excel自动识别。旧.xls需转换。未提交OAS崩溃后整批重放，尚无跨进程几何检查点。仍存活但无响应的服务不能安全强杀，任务持久保留等待人工处理。用户修改冻结工程须新建任务，不能混用旧记录。
- 新增用户明确授权随包公开的GD55图纸/工程/合成Excel；小偏移链路案例不代表原工艺输入范围全部适配。最终发布验收见V44_VALIDATION。

- V44本地5bab2c7干净回归中，gui_v42_saved_process在保存完成后的子进程关闭阶段出现一次无Python栈的Linux原生Segmentation fault；聚合正确判失败。同用例独立重跑未复现。Windows实际EXE重复启动/退出通过，不据此宣称Linux问题已修复。

- V44新增连通补偿仍是有界几何搜索，不是任意平面拓扑的完备求解器。不可移动异网端孔相碰、封闭阻挡等可能无可用解；明确拒绝提交比伪造连通图形优先。正面积电连接通过不代表最小包围量、线宽或线距通过。跨网络补偿启用时需联合核验，首次完整目录仍可能较慢。

- V46客户端支持项目目录内相对输入/配置迁移；已创建SQLite任务仍绑定原路径及冻结身份，移动项目目录后需新建任务。该限制避免复用其他目录的旧回执；旧输出与任务文件不删除。项目必须包含明确的工程JSON和目录内图纸；历史平铺工程先由主程序另存到项目文件夹。
