# 已知边界与后续重点

当前证据见[V42验证](V42_VALIDATION.md)与[详细数据](V42_cases.json)。历史问题在对应Git标签保留。

- 三个实图的全部需要追溯接口已覆盖，但部分极端仍有规则失败、折叠或连接候选失败。不得把覆盖率、几何有效或绿色区域当成生产良率。
- 多端合并域采用连续位移场；圆弧选项在多端域使用C1权重，不是任意多端精确圆弧。复杂回路、多DIE共网、窄区域仍可能需要人工调节或后续候选优化；无法分离时保留原铜并说明。
- 有限离散/网格不等于连续空间穷尽；灰色必须有充分概率上界，未知仍保留风险。
- 首次规划、新的强制/工艺配置和完整统计仍可耗时；局部拖动与缓存优化不构成整体速度或30 FPS保证。后续优先缓存跨DIE组合内重复的分支组装，再以相同几何/规则测量独立原生进程收益。
- 旧通用ABC后端遇到极小退化边会拒绝偏移铜输出并保留旧文件。V42产品入口固定输出名义零位，三个实图文件均通过闭合/重复/重合检查。
- 结果侧车需与工程一起保留；缺失、损坏、版本/几何/参数变化、未完成时恢复设置并重算。跨盘引用为绝对路径，换电脑可能需重算；持久快照与运行缓存清理不同。
- Windows托管验证不替代工厂离线镜像或物理GPU验收。保留CPU回退，本轮没有GPU提速证据。V41曾有一次未重现Linux退出异常，检查器继续按退出码和错误日志判定失败。
