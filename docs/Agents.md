# 每轮协作记录

根目录的 `AGENTS.md` 是工具自动读取的入口，本文件记录本地与远端共同维护的变更。开始一轮工作时先同步唯一主线 `main`，依次阅读入口、设计规范和最近一轮记录。完成后更新本文件，将代码、工程兼容验证和关键结果一起提交 GitHub，通过 PR 集成。后续轮次在最上方追加日期、版本、变更、测试、已知限制与 PR 链接。[协作与提交规范](../Agent.md)

## 2026-11-02 · V26 · 三自由度离散组合、缓存色和计算资源

本轮集成见 [GitHub PR #5](https://github.com/shiyuliuth-del/PLP_Die_Shift_Analyzer/pull/5)。

- 用户确认零幅度轴的系统偏差锁为零。活动轴取物理零、μ−B、μ+B，按真实数值去重。单颗典型 27 种包含首行；三个活动 DIE 共 19,683 种。全组合按页取值。
- 原固定铜规则只计算每颗 DIE 的局部项及可能接近的芯片对。两 DIE 的 729 行逐行与完整原图几何及 DRC 比对。GUI 和工程 CLI 使用 `core.evaluate(..., validate_extremes=True)`；只需连续模型的程序化调用可省略该开关。有限重点型变与连续统计验证分开记录。过孔离散足迹逐个按归属取并集。
- 缓存深浅与绿色安全状态共存，选中行保留真实底色。只读缓存键元数据，缓存命中、回看、正反动画和工程切换都须回归。
- 宽度检查线程使用独立 GEOS 几何上下文和空间索引。GPU 只在合格硬件上运行经数值自检的批次，有 CPU 回退。本机无可用的 CuPy/CUDA 后端。[实图性能记录](../results/performance_V26.json)
- schema 5 增加可选 `extreme_view` 与 `overlays.footprint`，旧工程采用第一页、全部组合和关闭足迹。[使用说明与复算口径](V26_使用说明.md)

## 2026-11-02 · V25 · 手动预演、真实窄口和视图标签

本轮集成见 [GitHub PR #4](https://github.com/shiyuliuth-del/PLP_Die_Shift_Analyzer/pull/4)。

- M 和数值输入共用姿态与双向插值缓存。手动接管时清空表格当前索引，点击空白首行要退出手动模式、拒绝过期任务并恢复全局判定。
- 普通结果与动画各有同值容量上限。回放和反向查找均只读已有文件。快速帧由动画包保存，不得按刷新次数淘汰终态。
- 宽度只报告有原始线路贯穿的真实相邻窄口。同束同壁的连续取样保留最紧的一处，保留分离通道。GD55 的点位复算使用三颗 DIE、九种姿态、固定 15/15/15 μm 规则。[实图记录](../results/width_V25.json)
- 工程继续使用 schema 5。可选的 `expanded_settings` 保存设置页已展开的标题，`settings.width_label_font_pt` 保存字号，旧版默认全部折叠和 8 pt。改字号、缩放、平移只应重排文字。
- Windows 源码入口为 `RUN.vbs` 或 `main.pyw`，EXE 保持窗口子系统。Linux 验证和模拟 Windows 控制台 API 均不能代替 Windows 桌面确认。[使用说明](V25_使用说明.md)

## 2026-11-02 · V24 · PATH、Q 编辑与相邻开口

本轮集成记录见 [GitHub PR #3](https://github.com/shiyuliuth-del/PLP_Die_Shift_Analyzer/pull/3)。

- 源图只读。零宽 PATH 在展开前排除并按实际引用数报告。单点圆和普通 PATH 保留顶层中心线，Q 编辑以源指纹绑定到当前工程，GUI 和 CLI 采用相同几何版本。
- 只在相邻实体之间检查通道。孔盘进入评估矩形即锁定完整投影，原有局部连接保持在对应侧别。实际线路单独检查封装外缘和内孔，等于本层线距通过。
- 显隐、低亮和选择只作用于绘图。必须回归隐藏参与层之后的方案、宽度行、统计与数值场，编辑之后的缓存和工程往返。
- 普通右键单击居中、拖框缩放，M 模式保留右键拖芯片。零位渐变默认开启，测试首次、缓存重播和关闭后的即时返回。标签第二行按保宽需求减当前净宽计算总收窄量，风险线路的局部斜纹位于矩形下方。
- 合成案例 P 与真实 GD55 回归分别检查指定构造和实际宽度输出。[本版操作与复算](V24_使用说明.md)

GD55 三颗芯片的名义位置有 5,267 个相邻截面，其中 4 个宽度不足、5 个需要局部收窄。三颗同取 −35 μm、−35 μm、−1° 时有 5,457 个截面，分别为 6 个不足与 17 个需收窄。九姿态中的 48,688 个正宽矩形均用独立多边形求交检查内部第三实体。比较单位为各姿态的相邻截面。[实图统计](../results/width_V24.json)

## 2026-11-02 · V23 · 固定 RDL 通道容量

本轮通过 [GitHub PR #2](https://github.com/shiyuliuth-del/PLP_Die_Shift_Analyzer/pull/2) 集成。

- 用户确认完全没有接入运动过孔的固定 RDL 网络整块保留，包括只连固定过孔的走线。运动网络的线路取名义穿越根数和局部原宽，分别计算保持原宽、收窄至工艺下限两种容量。三档配色为绿色、琥珀色、红色，绿色默认隐藏。
- 新增功能的存储是交付条件。工程保存开关、绿色显示状态和相关参数。维护者需同时验证旧 Jobs 缺少新字段时采用默认值、同一窗口换工程不会继承上一个工程的开关、新工程覆盖保存和再次打开能还原。
- 示例 O 用同一处通道复算三档结果。示例 N 验证只连固定过孔的线路整块保留。需复验相切、同网多次穿越、斜穿线宽、边缘通道、第三孔盘分段、两个 DIE 和自定义旋转中心，另在本机只读运行 GD55 名义状态与八个组合。
- 本版的结论限于已识别局部截面及保序穿线。分段后的绕行侧别和跨区连通还需核对。V22 已知的重构边框与修复补块事项继续跟踪。[使用说明与数字示例](V23_使用说明.md) · [已知问题](KNOWN_ISSUES.md)

V23 的 Linux 复算覆盖 GD55 三颗芯片、267 个保留对象、每姿态 6,609 个有原始线路穿越的截面。名义姿态各截面均能保持原宽。三颗芯片同时取 DX = −35 μm、DY = +35 μm、O = +1° 时，2 个截面宽度不足、1 个截面需局部收窄。计数单位是截面，同一对孔盘可以有多个截面。[九个姿态的全量统计](../results/width_V23.json)
