# 每轮协作记录

根目录的 `AGENTS.md` 是工具自动读取的入口，本文件记录本地与远端共同维护的变更。开始一轮工作时先同步唯一主线 `main`，依次阅读入口、设计规范和最近一轮记录。完成后更新本文件，将代码、工程兼容验证和关键结果一起提交 GitHub，通过 PR 集成。后续轮次在最上方追加日期、版本、变更、测试、已知限制与 PR 链接。[协作与提交规范](../Agent.md)

## 2026-11-02 · V23 · 固定 RDL 通道容量

本轮通过 [GitHub PR #2](https://github.com/shiyuliuth-del/PLP_Die_Shift_Analyzer/pull/2) 集成。

- 用户确认完全没有接入运动过孔的固定 RDL 网络整块保留，包括只连固定过孔的走线。运动网络的线路取名义穿越根数和局部原宽，分别计算保持原宽、收窄至工艺下限两种容量。三档配色为绿色、琥珀色、红色，绿色默认隐藏。
- 新增功能的存储是交付条件。工程保存开关、绿色显示状态和相关参数。维护者需同时验证旧 Jobs 缺少新字段时采用默认值、同一窗口换工程不会继承上一个工程的开关、新工程覆盖保存和再次打开能还原。
- 示例 O 用同一处通道复算三档结果。示例 N 验证只连固定过孔的线路整块保留。需复验相切、同网多次穿越、斜穿线宽、边缘通道、第三孔盘分段、两个 DIE 和自定义旋转中心，另在本机只读运行 GD55 名义状态与八个组合。
- 本版的结论限于已识别局部截面及保序穿线。分段后的绕行侧别和跨区连通还需核对。V22 已知的重构边框与修复补块事项继续跟踪。[使用说明与数字示例](V23_使用说明.md) · [已知问题](KNOWN_ISSUES.md)

V23 的 Linux 复算覆盖 GD55 三颗芯片、267 个保留对象、每姿态 6,609 个有原始线路穿越的截面。名义姿态各截面均能保持原宽。三颗芯片同时取 DX = −35 μm、DY = +35 μm、O = +1° 时，2 个截面宽度不足、1 个截面需局部收窄。计数单位是截面，同一对孔盘可以有多个截面。[九个姿态的全量统计](../results/width_V23.json)
