# Die Shift Analyze V30

## 在 Windows 启动

1. 当前分发的是 [V31 源码包](V31_使用说明.md)。解压并在目标 Windows 电脑上运行 BUILD.bat，将生成的 EXE 放到可写目录。
2. 双击唯一的 `Die_Shift_Analyze.exe`。首次启动在 EXE 旁创建 `Jobs` 和 `logs`。工程下拉菜单读取 `Jobs`，运行信息写入 `logs/runtime.log`。
3. 迁移旧工程时，把原有工程文件放进 `Jobs`。若工程使用相对路径，请保持对应 GDS 与工程的相对位置。程序重新启动会补建缺失目录，并保留现有工程。

图标中浅青色芯片相对固定层错开，橙色过孔标出移动方向。Windows 文件图标含 16、24、32、48、64、128 和 256 像素七档，程序窗口使用同一个图案。源码 Release 的 SHA-256 文件单独提供。

## 源码启动与构建

Windows 源码入口为 `RUN.bat`。双击使用现有环境启动，随后由 `pythonw` 打开图形窗口。Windows 执行批处理时可能短暂显示命令窗口；由源码构建的 EXE 直接使用 Windows 图形子系统。可以用 `DIE_SHIFT_PYTHON` 指向已有解释器，也可使用已激活的虚拟环境、项目的 `.venv` 或系统 Python。源码所需库列在 `requirements.txt`，不固定 Python 或包的版本。Linux 源码从 `python3 main.py` 启动。

开发者在装有 PyInstaller 和运行依赖的 **Windows** 环境运行 `RUN.bat build`，产物是 `dist/Die_Shift_Analyze.exe`。官方构建带 KLayout 几何模块；普通用户运行 EXE 时无需安装 Python 或联网补装库。源码也支持已安装的离线 KLayout 桌面后端。构建时图标写入 Windows EXE 资源，运行时工程目录以实际执行文件为基准。[PyInstaller 运行目录](https://pyinstaller.org/en/stable/runtime-information.html) · [单文件打包规范](https://pyinstaller.org/en/stable/spec-files.html)

## 接触标记

在“设置 → 接触标记”中独立控制以下两项。新工程和没有这两个字段的旧工程均默认开启。

| 设置 | 图形含义 |
|---|---|
| 显示过孔包围量范围虚线 | 浅青色半透明虚线。由当前运动过孔的实体轮廓向外增加最小包围量。 |
| 显示过孔线距范围虚线 | 浅紫色半透明虚线。在包围区域外再增加工艺线距。 |

轮廓随运动过孔、芯片和源图层显隐一起更新。圆孔显示圆形，非圆孔和带孔洞的复杂轮廓按实际几何绘制。开关立即更新图形和图例，接触位置、面积、概率及评估结果保持原来的工艺口径。保存后重新打开工程，两个开关分别恢复。

## 交互性能

连续平移或缩放期间每个刷新周期处理最新视角，复用仍覆盖视野的空间索引。选择图形时只重绘高亮和详情。过孔包围量与线距轮廓按可见范围批量提取，同一帧连续平移时复用已有边界。拖框退出会先擦除临时矩形。在 GD55 的两轮交叉顺序对照中，选中再取消的耗时由 121.3 ms 降至 9.4 ms，两个已算姿态的画面切换由 118.3 ms 降至 94.3 ms，连续平移缩放的整帧耗时约 118–119 ms。统计量为每轮样本中位数再取两轮中位数，包含窗口绘制和 Qt 事件处理。两版每个采样视角的过孔轮廓顶点、接触点和位移线坐标完全一致。[GD55 同机测量](../results/performance_V30.json)
