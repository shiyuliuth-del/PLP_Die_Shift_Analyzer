# Die Shift Analyze V20

本源码包不含任何图片、图表或截图文件。界面的图形和公式仍在运行时正常绘制；无需读取报告图片。研究报告和验证插图单独发布。

## 本版变化

- 重构预演由原始铜图形的连续位移产生。原孔盘边缘和相连材料点必须跟随运动，固定连接端保留；单纯新增孔盘拼接不再作为成功候选。短孔盘、中段连接、分支追溯使用多类位移场，失败保留原图并显示原因。
- 正反两个方向的同一动画路径共用已验证帧。完成一次往返后再次切换不重新求解；无位移状态固定保留。首次走一条新路径仍需验证中间帧，这与重算目标状态不同。
- 后台采样CPU负载和可用内存；资源充足最多并行两项独立预演，高负载排队。每项任务独占可变计算引擎，共享已完成的结果缓存；旧结果不会覆盖新选择。
- 设置中的最大缓存个数和清理按钮继续有效。重评估、主动清除、达到缓存上限或退出软件后，已清除的普通结果需重新计算。

## 启动与离线环境

Linux：`python3 main.py` 或 `bash run.sh`。Windows：双击 `RUN.bat`，使用已有完整Python环境。可用 `DIE_SHIFT_PYTHON` 指定解释器，用 `DIE_SHIFT_KLAYOUT` 指定已安装的KLayout程序。不会联网补装依赖。Windows离线打包入口为 `BUILD_WINDOWS.bat`。

支持Shapely 2.1的约束网格；在2.0环境中，只接受能完整覆盖源铜及孔洞的替代三角划分，不完整则跳过该候选族，继续其他位移场搜索。无CUDA时使用CPU。

## 操作与快捷键

打开GDS后手动设置用途和层叠顺序；新GDS不自动指定边框。评估前设置固定/运动线宽线距、包围量和各DIE偏移幅度。默认线宽、线距、包围量均为15 μm。偏移幅度是单边最大值。

完成方案评估后勾选“预演分析”，选极端情况或手动输入偏移。“型变校验”提供未适配原因；灰色是通过最终规则检查的型变铜，未通过恢复原图。DRC、运动概率、Space Map独立开关。

- F：恢复原视角。
- M：选择芯片；右键拖动平移，滚轮旋转，Ctrl+滚轮缩放；ESC退出。
- 常规视图：滚轮缩放，中键拖动。表格和运行信息框滚轮滚动行；不改变数字、下拉值或层序。

本机验证范围为Linux既有依赖、真实KLayout模块/桌面后端；不等同于Windows实机验收。有限候选搜索没有求得解时显示“未解”，不等于证明无空间可适配。源GDS保持只读。
