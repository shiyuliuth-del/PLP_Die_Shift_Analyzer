# V64 使用说明

## APD 规则输出

1. 在「设置 → 避让空间」选择显示范围和输出间隔。间隔默认 5 μm。各区域的最小线距按间隔上取整，重叠处用较大的要求。选择全封装时，运动区域之外使用原工艺线距。
2. 点击「APD规则输出」，选择从 Allegro X APD 23.1 导出的 `.dcfx` 模板，并把允许改线的固定 GDS 层对应到 APD 导体层。导出生成同名 `.il` 和 `.dcfx`。输出使用当前预览姿态的版图坐标。
3. 在 APD 打开目标设计，执行 `skill load("输出名.il")`，再执行 `skill dsa_apd_regions()` 创建约束区域。随后在 Constraint Manager 使用 Merge 导入同名 `.dcfx`，检查 Region 工作表和 line-to-line spacing 数值，再运行 DRC。

规则文件按照 APD 23.1 实际导出的 Region 结构生成。区域轮廓由 SKILL 写入版图数据库，规则文件按同名 Region 应用线距。使用 Merge 模式保留目标设计的其他约束。 [Cadence SKILL 指南](https://community.cadence.com/cadence_technology_forums/pcb-design/f/allegro-x-scripting-skill/58594/introduction-to-skill) · [Cadence 约束区域说明](https://community.cadence.com/cadence_technology_forums/pcb-design/f/pcb-design/16682/defining-region/1178303)

## 删除和撤销

- 在版图画布选中图形并按 Delete，移除该工程中的源图形。保存工程后，重新打开仍保留删除结果。关闭重构自动计算时，待处理的删除轮廓以淡红填充显示，点击「重构计算」后清除标记。
- 按 U 撤销，按 Shift+U 重做。也可点击「设置 → 通用」中的两枚箭头。历史默认保留 10 步，覆盖图形和节点编辑、动区编辑、宽度分析忽略设置、测量和预览姿态。工艺及其他参数设置独立于撤销。
- 「清除当前工程缓存」会清除该工程的撤销历史，清除全部缓存会同时清除所有工程的历史。

## 孔盘圆点模式

「设置 → 重构预演」中的「允许运动孔盘随动」默认关闭。

- 关闭时，自动划分、手动框选及拖动都使用直线边界。已有圆点迁移到同一走线上最近的可用直线截面。
- 勾选后，运动过孔侧可在拖到实际连接的孔盘并超过触发余量时变成圆点。自动划分也可以采用整孔盘模式。固定过孔侧始终使用直线。
- 工程会保存开关。旧工程缺少此选项时按关闭打开。重构预演和动静区 DXF 使用同一设置。
