# Die Shift Analyze V57

## 本轮修复与新增

- **随动图形与复杂铜面动区修复（`GD55_1119`）**：
  - 修复整块随动图形（如 `(-1858, 237)` 与 `(-1149, -229)`）在 `DIE2 X- Y- θ-` 发生固定过孔失联时以原位红色残影覆盖的问题，诊断标记改为绑定实际随动后的铜形位置，并同步让离散全组合扫描尊重固定过孔联动模式（开启全局/分别联动后上述两处正常随动无异常）。
  - 优化宽铜面/分叉动区规划与斜切限幅：自动吸收相邻过近、无端孔的狭窄浮动刚体条并防止宽面长切口在大位移下过度旋转交错，解决 `(-1696, -2198)` / `(-1698, -1919)` 生成双窄条及多条边界横竖交错的问题，同时消除 `(-1875, -2227)` 处由异常斜切引起的虚假 `最小内角不足` DRC 标记。
- **低概率极端情况低亮显示**：
  - 在重构预演的极端工况下，若当前极端工况概率低于良率级别要求（`P ≤ 2Φ(-k)`）或动区已证概率上界低于门限，对应动区填充、红框与当前 DRC 标记自动低亮/虚线弱化显示，表格提示与状态栏同步标注，便于直观区分低概率风险。
- **忽略图形自动清除动区**：
  - 将固定 RDL 图形设为忽略重构（或切换为整块静止/整块随动）时，自动删除其上的全部手工/自动/框选动区；被显式忽略的图形不再被旧选框复活。
- **关闭自动计算时的多步操作反馈与随动配色**：
  - 关闭自动计算时，对同一图形执行多次操作（如先忽略再改为随动、删除动区再框选等）会按操作类别呈现不同颜色的虚线高亮，并在画布及右键菜单摘要中显示累计待算操作标签（如 `待算：忽略·随动`）。
  - 提升整块随动图形的浅紫填充辨识度（`#c9b3eb`, alpha `0.45`）并修复 DIE 内图形与自动/手动随动覆盖优先级，确保正式计算后颜色与运动方式一致。
- **层叠显示表格新增「选中」列**：
  - 在偏移栏目层叠表的「显示」列右侧新增「选中」复选框列，默认仅「固定 RDL」层勾选，其余层不勾选；仅勾选的层允许被鼠标点选或框选选中，取消勾选自动清除该层既有选集，配置随工程保存。
- **重构预演性能继续优化**：
  - 跳过仅含忽略图形硬失败时的冗余整图 `quick` 回退求解，并对型变缝隙重叠检测增加包围盒与零重叠快路径，进一步提升极端工况切换流畅度。

## 既有能力保持

保留 V56 随包 `Jobs/GD55` 与 `Jobs/GD55_1119` 公开案例、跨缝拖动、框选落点标记、视野外弹窗自动隐藏及 `RealDataAnalyse` 联合发布规则。详见 [V56 使用说明](V56_使用说明.md)。
