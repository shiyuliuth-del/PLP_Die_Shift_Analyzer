# V42 使用说明

本轮变更和算法在[现行合同](DESIGN_REQUIREMENTS.md)与[AI交接](AI_HANDOFF.md)。实际验收范围见[验证记录](V42_VALIDATION.md)，交付以V42 Release为准。

- 工艺新增“图形距边框”，默认10μm。重构与宽度分析分别按这个边距检查，线宽/线距容差不改变它。
- 边界角度默认“重构区优先”。两端柄均为蓝色，悬停脉冲更轻。拖动中更新当前边界角度，完整规则检查异步补齐。
- 分叉路径有共用名义定位，连接的适配域合并；单条路径串联区碰接后合并。合并后仍须复核几何、线宽、线距、包围量和封装边距，不能仅凭颜色判断完成。
- 忽略重构的铜按实际连接DIE随动；多个DIE先按连接分支分开，无法确定分离时保留原铜并明确提示，不任意选最近DIE。
- 整孔盘圆点只允许本图形真实相连的端孔。设置“整孔盘触发余量”默认5μm；拖过余量且鼠标位于对应孔附近才转成圆点。非相连孔不能触发。右键增加动区按点击源位置定位，不在别处替代添加。
- 未有方案评估结果时，分析开关先排队执行方案评估，再生成预演及完整极端目录。切换工程同样适用。
- 设置的硬件栏目可开启保存运算结果并指定临时文件目录，默认与工程同目录。工程JSON引用带摘要的 `.dsresults` 纯数据侧车；一起保留才能跨次启动恢复计算结果。缺失、损坏、版本/图纸/参数变化则恢复设置并重新评估。运行缓存清理与持久工程快照是不同对象。
- 修复补块已删除。旧工程的相关选项忽略，其他选项照常恢复。
- 动静区输出始终使用名义零偏移轮廓：仅芯片/封装边框以及固定RDL的A动区/B平移/C静区。普通DXF仍输出当前完成姿态。ABC只写开放真实边界，回读闭合/重合校验后才替换目标。

Windows完整解压后RUN.bat运行、BUILD.bat在目标机器打包。正式源码包无图纸、图片和EXE。已知边界见[已知问题](KNOWN_ISSUES.md)。
