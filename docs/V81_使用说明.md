# V81 共享离线授权

- `LicenseManager_BUILD.bat` 独立构建管理员签发工具。双击 `dist_admin\LicenseManager.exe` 后生成密钥对或加载已有加密私钥。新签发只需 Machine ID。
- `BUILD.bat` 使用管理员公钥构建 `dist` 内的 Die Shift Analyze 和 RealDataAnalyse。默认自动读取签发工具生成的公钥 `%LOCALAPPDATA%\DieShiftLicenseManager\keys\public_key.pem`。自选密钥目录可通过源码根目录的 `public_key.pem` 或 `DIE_SHIFT_LICENSE_PUBLIC_KEY` 指定。
- 将一份管理员签发的 `.lic` 放在两个 EXE 的同一目录。程序启动时自动验证，也可在授权窗口点击「重新检查」。原有从界面导入至当前用户目录的许可仍可使用。实测交互与无界面任务均使用同一许可。
- Windows Machine ID 保持 V80 已验证口径，继续使用 UUID 和本机 IPv4。正式公钥缺失时，授权窗口独立显示能取得的 Machine ID。
- Release 提供源码及 SHA-256。管理员加密私钥、签发历史和通用许可保存在部署环境中。
