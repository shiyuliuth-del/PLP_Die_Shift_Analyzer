# V70 使用说明

## RealDataAnalyse

- 「任务运行」的「结果自动建Cell」默认不勾选。封装铜、边框和诊断标记直接写入 TopCell。勾选后按原层级创建封装及内部 Cell。两种模式都保留模板图纸的独立 Cell。
- 「忽略测量失败」新项目默认勾选，跳过有机台测量失败的封装。取消勾选后使用失败行的有效偏移和旋转。现有项目的显式保存值、已创建的任务与计划继续沿用其设置。
- 「忽略重构」沿用原来的 X/Y/角度阈值。符合条件的封装按名义图形放置。
- 「所有 Excel 共用列映射」位于工作表行的最左侧。任务运行和计划任务表格随窗口高度自动展开。
- 可输入项目文件夹后按 Enter，也可用原来的选择按钮。验证通过时输入框变为浅绿色，路径或项目无效时变为浅红色。

前序功能参见 [V69 使用说明](V69_使用说明.md) 和 [V68 使用说明](V68_使用说明.md)。
