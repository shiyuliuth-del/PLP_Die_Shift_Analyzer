# V37 固定 RDL 重构切口

从“结果图形”打开“重构预演”并选定一个有偏移的姿态。可以拖动对应单串的切口线，松开后更新移动铜、补线与净距。切口方向固定，可移动范围从本串落盘外侧到能切过该段铜的末端。右键或双击手动切口可恢复自动位置，也可从表格下方清除全部手动切口。

设置中的“自动搜索切口位置（D = 0）”默认关闭，此时零距离设置使用等面积落盘直径的 2.5 倍。启用时从有限候选比较切口横截面和移动铜及补线到参考铜的净距，优先选择满足有效线距的候选。正数 D 继续使用指定距离。候选搜索有上限，最终仍须按完整重构结果核对。

重构表的“间距”以 μm 给出当前移动铜及补线到同层异网最终铜的最小距离。低于有效线距时标注不足。重构变化只用于当前姿态几何与测量，V36 的宽度概率和 DXF 参数详见上一版说明。工程仍采用 schema 5，缺少手动切口的工程以空集合打开，切口设置参与重构缓存键。

[宽度概率与 DXF 说明](V36_使用说明.md)

搜索候选按参考铜比较，最终净距按所有异网重构铜重测；最终仍可能显示不足。候选预算未覆盖全部连续位置，不能推断其他位置一定不可行。动画使用有界分区缓存，临时结果不会被保存为手动切口。

源码启动先离线检查已有依赖，不会联网安装。`--gpu-info` 保留独立诊断；Windows源码入口仍为 RUN.bat，构建入口仍为 BUILD.bat。
