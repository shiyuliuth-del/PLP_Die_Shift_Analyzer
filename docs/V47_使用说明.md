# Die Shift Analyze / RealDataAnalyse V47 使用说明

V47把实测输出改为按指令计算，并修正GD55的重叠端孔、共用分支规划和圆点往返拖动。普通交互仍先方案评估，再开启分析；实测模式独立于这条交互流程。

## 实测输出

输出页的“实测输出设置”默认折叠，点击展开输出目录和资源参数。没有工程也可以开启接口；此时等待`project.open`。有工程则先自动保存、冻结工程数据。若已有计算运行，开关暂时置灰，完成后自动启用。

`main.py --measured-output --ipc-endpoint <入口文件>`无需`--project`；指定工程时只载入并建立连接快照，不恢复旧分析任务、不计算良率，也不自动预演。`info.ready`表示有效工程已冻结，**不表示完整方案评估或全姿态DRC通过**。

`preview.submit`只重构指定姿态并显示；`batch.submit`只重构并积累输出。两者检查最终铜的电连接、源拓扑、异网隔离和禁布区，不启动三方案、宽度分析、全局尺寸DRC、概率或良率任务。第一条指令建立所需名义路径，后续并行任务复用；可显式发送`session.prepare`提前准备。设置的连接样式、手工动区和旋转中心仍生效。尺寸规则不足与电连接失败有不同含义，快速输出不等于工艺签核。

取消、错误回执、旧目标保护、分阶段partial OAS和项目冻结身份均保留。具体命令见[IPC接口](MEASURED_OUTPUT_API.md)。RealDataAnalyse仍随包，按项目文件夹联动实测输出。

## 重点组合

首行为所有芯片零偏移。其余重点组合同步遍历可运动DIE的非零局部状态，不再加入“只移动部分芯片、其余可运动芯片停在零位”的行。三轴幅度均为零的DIE保持原位。

设第i颗DIE去重后有nᵢ个非零离散状态，重点非零行数N=max(nᵢ)。第j行取该DIE第`j mod nᵢ`个非零状态；没有非零状态的DIE取零。每颗芯片的所有局部极端均覆盖。例如多颗三轴活动DIE共有26条非零重点行，加首行共27行，而非27的DIE数量次方。它不覆盖所有相对运动组合，完整交叉组合须选择“全部情况”。

重点良率沿用所选代表单元概率归一化口径。未选状态不参与，也不标为通过。DRC、重构、宽度和良率使用相同目录；过滤无问题仅隐藏行。与V46的具体选择集合不同，旧分析缓存不混用。

## 界面与重构

- 打开GDS/OAS按钮为浅绿色，与方案评估区分；删除工艺说明文本。
- 图层表下缘可拖动调整高度，工程保存/恢复高度；图层显隐只影响显示。
- 自动规划优先让同属一个DIE的运动孔盘留在同一刚体侧，共用主干设置动区；手工仍可沿各分支调整。
- 近乎重合的运动/固定端孔不再虚构极短独立路径；实际固定孔仍参与最终连接和包围量检查。圆点可沿正确分支反向拖回边界线。
- 禁布区允许共边，但不允许正面积进入。重构尝试绕开；确实无法同时保连通、隔离与禁布区时拒绝新铜并保留上一完成状态。

旧schema5工程可读，显式参数保留；新增表格高度缺省300像素。实测开关不会通过普通打开工程偷偷启用。测试范围和限制见[V47验证记录](V47_VALIDATION.md)。
