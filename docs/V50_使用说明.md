# V50 使用说明

本版与 RealDataAnalyse 联合发布，只提供源码、RUN.bat/BUILD.bat及校验值。

- 重点组合覆盖任意两颗活动DIE的完整局部状态配对，包含靠近、远离和反向旋转。三颗各27状态的GD55为729个重点（包含零位），全部仍19683。只计算所选范围，重点良率在这些代表单元内归一化；不冒充完整连续良率。
- 设置→重构预演→自动计算默认开启。关闭后参数/边界编辑暂存，点击右侧重构计算才统一应用；画布保留已完成结果，待应用时不可导出为新结果。
- 输出顶部为输出GDS/OAS，输出当前已完成姿态和实际型变铜，所有已导入层默认保留；原图只读。三个参数组默认折叠且统一样式。GDS/OAS可选图层、Merge、格点和GDS节点上限。动静区DXF仍输出零位ABC。
- 开启显示DRC问题时，GDS/OAS附带独立ERROR数值层；OAS同时声明ERROR层名，GDS使用ERROR子Cell（GDS格式自身无标准图层名称记录）。四角取实际见证的定向包围矩形，不把已有姿态再旋转一次。严格制造导出仍拒绝未解决连接的诊断铜。
- 实测输出的芯片边框跟随每颗DIE及其真实旋转中心；ERROR支持旋转矩形和旧回执。新目录含marker_corners_um、marker_angle_deg以及可用的actual_um/actual_deg；原bounds与分页保持兼容。
- 工艺中的DRC设置尺寸规则；设置中的DRC逐类设显示/检查。隐藏不改变数值；不检查的类别不运行其规则判定、不进入DRC及规则良率统计。重构能否形成有效铜及物理电连接属于生成结果完整性，仍不可将断连/短路作为成功制造输出。宽度通道分析是独立几何容量功能。
- DRC表的实际列显示实际宽度、距离、包围量、角度等；无法可靠量出的条目用—，不拿要求值或包围盒尺寸冒充测量值。
- K进入测量，第一次单击起点、第二次单击终点；自动吸附可见几何顶点/边，Ctrl锁定八方向、Shift锁定水平垂直（同时按时Shift优先）。Esc退出，Shift+K或Ctrl+K清空。标尺不导出为制造铜。
- 安全范围及无接触良率设置合并至结果分析，仍只在主动访问分析页时计算。

工程保持schema5；缺失字段用默认值、旧显式值保留。栏目展开状态随新名称迁移。结果版本改变后旧计算侧车失效但工程仍正常打开。
