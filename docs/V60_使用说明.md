# V60 生产测量导入

将每颗芯片的测量 CSV 或 XLSX 放在项目的 `RealDataAnalyse/Excel/<芯片目录>` 中。目录名可以使用数字、字母、中文等当前操作系统允许的名称。同目录多份文件合并读取。

芯片目录名用于显示和回溯原始记录。程序用机台各位置的理论中心与图纸芯片的相对位置推断对应关系。旧工程的 `die_order` 与实际匹配不一致时，按理论坐标匹配并给出警告。全局实测中心和测量角度决定最终芯片姿态。当前默认毫米转微米的比例和匹配容差可在 `measurement.scale_um` 与 `measurement.match_tolerance_um` 中调整。

- 偏移列缺失或者有不可读值时，可从完整的实际中心与理论中心恢复偏移信息。
- 同位置实测姿态完全相同的重复记录合并。有成功记录时可跨过重复的失败记录。
- 跳过孤立坏行、明确测量失败、缺测和冲突封装，继续创建其余封装任务。单个文件的结构有问题时，其余文件继续参与匹配。
- 若整批无法可靠匹配图纸位置、没有完整封装、源文件在读取中被修改或发生存储故障，停止创建任务并说明原因。

任务页和进度条显示跳过封装及警告数量。日志和命令响应显示部分警告，所有明细可在项目任务数据库的 `events` 表查看。明细提供文件和行号，便于回到机台原表核对。原始测量数据保持只读。

随包 `Jobs/SH22` 保持 400 个合成封装。旧式平铺 `Measurements` 文件继续按原封装ID流程导入。运行和构建入口见 [V59 使用说明](V59_使用说明.md)。
