# Die Shift Analyze V72

关闭「自动计算」时，框选动区和右键修改「动区间随动」会显示待算标记。连续使用自由框和符合边界角度的选框时，软件记录实际操作顺序。点击「重构计算」统一应用。删除一个图形上的旧动区后再框选，其他图形原有的框选保留。

切换极端情况时，已选的铜随姿态更新高亮；单击空白处清除。动区之间的刚性铜段可以单独点选。跟随幅度小的一侧稍深，跟随幅度大的一侧稍浅，两侧平均使用图层原色。适配区沿用本身的 DRC 颜色。

动静区 DXF 始终以零偏移输出轮廓。动区间铜段通过工程中配置的幅度判定分层。

| 动区间策略 | DXF 分层 |
| --- | --- |
| 跟随幅度大的一侧 | `_A` |
| 跟随幅度小的一侧 | 小侧有运动幅度时为 `_A`，小侧幅度为零时为 `_B` |
| 两侧平均 | 两侧均静止时为 `_B`，其余为 `_A` |

SH22 验证坐标为（−241964, 245776）、（−242540, 245161）和（−242885, 246197），单位为 μm。验证覆盖重新框选、相向路径、同一铜图形内相邻框选和分叉上的局部动区。具体偏移下仍以完整 DRC 与电连接检查为准。

Windows 用 `DieShiftAnalyze_RUN.bat` 和 `RealDataAnalyze_RUN.bat` 启动。需要本地单文件 EXE 时运行 `BUILD.bat`。
