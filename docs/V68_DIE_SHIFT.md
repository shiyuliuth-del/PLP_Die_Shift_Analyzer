# V68 预演软件变更

- 图形上全部关联 DRC 均已忽略时，预演动区以绿色通过样式填充，不再绘制该问题轮廓。零位汇总还要满足当前范围内的相关故障姿态均已忽略。连接失败仍按独立电气判定显示。
- 同一图形含多个动区时，极端姿态的故障轮廓与断线虚线只绘制在实际故障范围。该图形上正常动区的铜和着色保留。
- 在「设置 → 重构预演」勾选「自动忽略低概率DRC」可按当前计算目录自动忽略。概率由整数系数与十进制指数相乘，默认 1 × 10⁻⁶。按规则及源对象计算联合离散事件概率，计入积分误差后仍严格低于阈值才忽略。关闭会清除自动及手动忽略记录。该设置不跳过检查，也不更改重构良率、ERROR 图层和实测原始问题目录。
- 「拖动吸附」与「吸附强度」同一行。拐角吸附预留为 0 时按画布比例取 5 像素对应的图纸距离，−1 时关闭拖动拐角吸附，正值可指定 μm。拖动结果仍应形成有效截面。
- 补偿列默认 0.000 μm，按图层保存。编辑器内释放左键或失去焦点后，移动鼠标不会继续换行。工艺的最小图形面积归入「其他」，原「图形过滤」展开状态迁移到该栏目。

## 实现与兼容

`drc_waivers` 以真实检查见证关联图形和极端姿态。自动忽略按规则及源对象聚合同一事件，重复位置只计一次姿态质量。风险和重点模式沿用所选目录内的条件概率。有限离散概率不表示连续输入空间的安全证明。电连接、异网接触和禁布区仍保留。

实测 IPC 可在 `batch.begin` 协商 `allow_drc_skip`，再为指定 `batch.submit` 传 `skip_drc`。服务仍重构并核验实际连通、异网接触与禁布区。跳过普通检查的回执标为 `fixed_rdl_drc_checked: false`、`drc_passed: null`。原图直出独立使用，两个策略不能同时为真。

多边形导入避免无 PATH 时重复展开空路径和读取路径标签。ABC 补偿归属使用空间索引，只与相交候选比较。重构联合核验对未变化的名义铜复用几何身份。
