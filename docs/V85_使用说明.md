# V85 示例工程精简、边界贴近过孔、XJ88 静止校验与失败姿态刚体铜显示

- **打包后仅生成 SH22 示例**：双击构建的 `Die_Shift_Analyze.exe` / `RealDataAnalyse.exe` 时，安装目录的 `Jobs/` 只自动生成 `SH22` 一个示例工程。`GD55`、`GD55_1119`、`XD46_SC9211`、`XD46_SC58512`、`XJ88_GDM32311` 仍随源码包提供用于复现与回归，但不再在启动/打包目录中自动出现。
- **重构边界可贴近到过孔相切**：手动拖动或框选动区边界时，限位由「孔盘（过孔＋包围量）外缘」放宽到**与实际过孔相切**的位置。运动侧边界可进入孔盘环形区域直至运动过孔边缘，固定侧边界同理贴近固定过孔；自动生成的动区仍从孔盘外缘开始，保持原有矩形连续概率证书与默认行为不变。
- **XJ88_GDM32311 验证工程**：新增 `Jobs/XJ88_GDM32311`（工程 JSON＋GDS）。已逐姿态核对 `(5,-800)`、`(408,-398)` 两处「忽略重构→整块静止」图形在全部 27 个离散极端下均保持图纸坐标不动（替换铜与源铜完全一致），右键「整块静止」流程亦复验通过。
- **失败姿态保留刚体铜的偏移**：当型变后出现红色问题（无法连通、短路、分叉碰撞等）时，只有重构动区（过渡区）以红色虚线标识位置；随运动过孔运动的铜仍按所属 DIE 正常偏移，随固定过孔不动的铜保持原位，不再把整个图形冻结在零位。严格制造输出仍拒绝带问题的铜。
