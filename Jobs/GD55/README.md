# GD55-1105 联合测试案例

本目录按用户要求随两个软件一起发布。`GD55_1105.gds` 为既有GD55测试图纸；`GD55.dshift.json` 使用相对路径，保留已有用途、层序、15μm工艺及±15μm/±1°输入设置和动区编辑。解压后不要拆开这两个文件。

三份 `GD55_SYNTHETIC_DIE*.xlsx` 各对应一颗DIE，12个封装按相同文本ID匹配，4列×3行放置，间距12000μm。偏移为可复现的**合成测试值**，不是生产实测或统计样本。默认Measurements表交替使用全零位及DIE1仅X偏移1μm（DIE2/3保持零位），中心留空沿用工程；这两姿态已用于真实严格批量验证，不代表±15μm/±1°全部通过。

每份Excel另有Diagnostic表：第一封装零位，其后k=((i×(die+2)) mod 11−5)/5，dx=k/100μm、dy=−k/200μm、角度=k/10000°，i从1起。该表保留了旧算法曾触发连接失败的小偏移，作为回归压力输入；新算法修复后可以成功，不预先假定它必须失败。将列映射表格上方的工作表改成Diagnostic并新建任务即可运行。实际完成/拒绝以当前软件回执为准，不能用allow_failed绕过电连接、拓扑或异网接触的硬失败，也不能把已输出当作完整DRC或生产合格。

1. 双击 `RealDataAnalyse/RUN.bat`，点击“选择项目文件夹”并选择此 `Jobs/GD55` 文件夹。
2. 客户端自动读取本工程及三份Excel，并启动/联动同目录 Die Shift Analyze；等待准备完成，连接状态和启动按钮为绿色。
3. 勾选三份Excel，工作表选择Measurements，核对DIE数量3。“校验并创建任务”后点击“运行 / 继续补算”。任务默认在Tasks，最终OAS默认在Output，日志在logs；这些目录属于本项目。
4. 在KLayout打开最终OAS，TopCell应包含12个Package实例，其左下角依次为(0,0)、(12000,0)…(36000,24000)。完成/失败与计数在底部进度条、记录表及可展开的信息输出中查看。

首次准备需要读取图纸、评估并规划共用动区；依硬件可能耗时。不能把窗口出现当作ready。已有服务工程与本项目不符时客户端会在服务空闲后联动打开；有活动任务时拒绝切换，完成任务后再点击“启动预演软件”。

本案例不会改变源GDS。服务可能更新保存的工程JSON和创建结果侧车/日志，测试前可复制整个案例到工作目录。正式包不含OAS结果或运行缓存。测量模板与严格的缺测/重复校验见 `../../RealDataAnalyse/README.md`。

在已提交的联合重构版本cef1017上，Measurements与Diagnostic各12封装均完成；Diagnostic全部12个封装逐层展开与独立单姿态GDS的XOR为空。另测两组±15μm/±1°姿态时，预览和批量接口一致拒绝已知异网接触，未生成OAS。该记录只覆盖这些姿态，最终版本验收见仓库docs/V44_VALIDATION.md。
