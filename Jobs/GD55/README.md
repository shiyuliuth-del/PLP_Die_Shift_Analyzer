# GD55-1105 联合测试案例

本项目随两个软件一起发布。GD55_1105.gds为授权测试图纸，GD55.dshift.json以相对路径引用它，保留原用途/层序、15μm工艺及±15μm/±1°工程范围。三份GD55_SYNTHETIC_DIE*.xlsx各对应一颗DIE，按文本package_id匹配封装。全部偏移是可复现的合成测试值，不是生产实测数据或统计分布。

## 可选工作表

| 工作表 | 封装数 | 用途 |
| --- | ---: | --- |
| Ordinary | 60 | 普通混合偏移：10列×6行，每个位置的三颗DIE都有独立的ΔX、ΔY和旋转角度，全部显式填写；XY在±8μm内，角度在±0.3°内。固定种子490060的分层取样，包含正负和不同幅度，180组DIE姿态不重复。 |
| Stress | 42 | 单DIE X/Y/旋转边界、三DIE同向和相反方向、混合旋转、绝对自定义中心、微小偏移、超范围压力及已复现连接失败。7列×6行。 |
| FailureRecovery | 6 | 零位→DIE1连接失败→微小混合偏移→DIE2连接失败→DIE3连接失败→零位，专门验证失败项保留正常铜及后续封装继续输出。3列×2行。 |
| Measurements | 12 | 历史小偏移基线，零位与DIE1 X=1μm交替。原数据/格式/冻结窗格保留。 |
| Diagnostic | 12 | 历史微小偏移压力回归，原数据/格式/冻结窗格保留。不能预先假定每个新算法版本都必须失败。 |

全部表的A:I列沿用原接口字段，长度μm、角度度。H/I中心留空表示工程中心，Stress的CustomPivot行显式填(0,0)。K/L列说明该位置的具体工况和目的，软件不把说明文字当作偏移。每个位置均有明确的每DIE XYZ值；单轴/锁零/全零行是有意保留的控制输入。

## 已实际复现的连接失败

使用本目录原工程和图纸，在V48严格实测模式实测以下三行均返回无法保持电连接/原拓扑或无法避开异网接触。每行只有列出的DIE运动，其他DIE的XYZ全为0，旋转角度为0°。它们超出工程工艺范围，仅用于稳定验证错误处理。

## 运行

1. 启动RealDataAnalyse，选择此Jobs/GD55项目文件夹。使用配套支持局部问题输出和ERROR层的软件版本。
2. 勾选三份Excel，共用映射，表头行1。项目默认已选择Ordinary普通偏移表；复现错误处理选择FailureRecovery；扩大边界覆盖选择Stress。三个文件必须选择同一组封装。
3. 点击“创建任务”，再“运行 / 继续补算”；也可分别创建计划任务依次执行这些表。修改输入选择或工作表后须新建任务。
4. 所有封装的摆放间距为12000μm。检查最终OAS中的TopCell封装数量、指定位置及各DIE对应的G_ERROR_封装名_DIE_编号子Cell；ERROR层矩形表示DRC/连接问题范围，公共无唯一DIE归属的问题位于DIE_0。问题位置被移除不意味着该封装工艺合格。

Output成功后只有一个最终OAS。任务在Tasks，中间文件及问题目录在Cache，日志在logs。选择另一工作表再次输出会归档旧结果到Cache；源码包不附运行OAS或缓存。原GDS始终只读。普通、边界和错误恢复的实测验收范围以仓库最终版本验证文档为准。
