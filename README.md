# Die Shift Analyze V21

GDS芯片偏移分析，长度单位为μm。V21修复不同芯片金属起始层导致的Pad不随动，增加当前姿态的局部宽度分析（落盘 air-gap，含固定RDL重构预演）；用彩色矩形标记窄口、用轮廓高亮风险线路。失败型变保留原图并说明原因。

- [本版使用说明（随源码提供）](docs/V21_使用说明.md)
- [研究报告](https://github.com/shiyuliuth-del/PLP_Die_Shift_Analyzer/blob/main/DIE_SHIFT评估报告.md)
- [本版图文验证报告](https://github.com/shiyuliuth-del/PLP_Die_Shift_Analyzer/blob/main/docs/V21_操作与验证说明.md)

源码ZIP不含图片或图表文件。界面图形和公式由程序动态绘制，报告图片单独提供。

## 启动

```bash
python3 main.py
```

Linux可运行`bash run.sh`。Windows双击`RUN.bat`：使用已有Python环境，自动识别KLayout模块或已安装的桌面程序，**不联网、不创建空环境、不补装依赖**。可用`DIE_SHIFT_PYTHON`指定已有完整解释器；KLayout通常从PATH、环境变量、注册表或常用安装目录找到，也支持`DIE_SHIFT_KLAYOUT`指定exe路径。仅安装KLayout不能替代本应用的NumPy、Qt等依赖；已有环境不完整时会明确提示。

`TEST_WINDOWS.bat`检查默认与强制桌面后端。`BUILD_WINDOWS.bat`在已有完整PyInstaller环境中离线构建EXE，源包同时包含桌面调用宏。此次仅输出源码包；已验证Linux上的真实KLayout桌面进程，未执行Windows实机验证。

## 操作

1. 顶部Jobs工程下拉选择即打开；空白为新工程，新保存输入名称，已有工程直接覆盖。
2. “偏移”中打开GDS，指定边框及运动/固定RDL、运动/固定过孔。每层checkbox独立显隐，不参与层默认隐藏。从行内任意位置拖动调整上→下层序，每颗DIE的局部末端金属应对应真实芯片接触。
3. 芯片数量、尺寸、RDL层数、过孔几何自动读取。工艺分别设置运动/固定线宽线距；输入幅度为最大随机偏差；只通过良率级别下拉选择0–12或∞。非零有限k使用母标准差=B/k、在最大幅度盒内截断归一化的正态分布；0沿用最近有限非零级别（首次6）的概率尺度，不筛除边界内概率；∞或具体预演按当前几何二值判定。
4. 只有实际运动过孔—固定RDL接口参与不足及叠加；过孔—过孔仍可传递归属。完全没有连接、或同时连到多颗芯片而无法作单一刚体的运动层金属，按位置归到最近的DIE（报告附录列出推定归属）；运动过孔与固定RDL之间夹着固定过孔层时，接触会沿层序找到真正压着铜的那层固定RDL。详见“信息”页的图层随动设置与报告附录。
5. 评估后选择极端状态或手动指定DIE的DX/DY/O。标签页右侧的Space Map默认关闭，与运动概率独立。两圈虚线表示最小包围/再加线距，红圈与灰线定位其他网络接触，三个方案均以红色填充实际侵入面积，灰色虚线连接当前孔中心。极端组合按输入幅度生成，35 μm不会被置信半径放大为39 μm。
6. 边框不参与选择；左键单击逐层循环选中，空白单击或ESC取消；从左向右框选完全包含，从右向左框选所有相交图形。图片滚轮缩放、中键拖动；输入控件禁止滚轮改值。窗口改变时绘图区填满可用区域，保持X/Y等比例。良率级别变化会实时重算并更新显示，其他工艺输入保留既有报告直到再次评估。

7. 单击层/类型格子调整颜色和透明度。工艺右侧“设置”集中配置概率算法、精度及Space Map配色和平滑；可选确定性积分，无随机采样。示例D演示芯片外扇出，示例E演示连续型变、邻网限制和原图细颈，示例F演示逐芯片幅度及两轮释放窗口。Space Map可扩展至整个封装，非运动区域用基础线距。勾选插值运动后可设置时长上限、速度级别和FPS，默认时长上限1000 ms、30 FPS；预演速度和接触位置视角速度分别设置，实际计划时长随移动距离变化。结果分析中的方案比较、安全范围图和预演统计可拖动分隔条调整高度。

图片中按 **F** 恢复原视角，**M** 选择DIE后右键拖动、滚轮旋转、Ctrl+滚轮缩放，**ESC** 退出。表格和运行信息框支持滚轮上下滚动；数字/下拉值及层序仍禁止滚轮修改。“DRC问题”位于“叠加运动概率”左侧，可在未评估、未型变时独立检查。新增示例G展示小偏移孔盘适配及780 μm三段追溯。

旧晶圆/板段工程自动转换为运动/固定用途；保存的层序保持原样；新GDS按读取顺序列出，只有手动拖动改变层序。GDS中的TEXT用途标签可保留，但新导入不会据此自动设置用途。

默认有限k按每接口接触概率p与2Φ(−k)比较；程序用概率上下界确认，无法决定者显示“概率待细化”，不把零采样命中当作通过。概率云显示整孔覆盖率，以透明度和颜色同时区分概率；默认不描画最大幅度包络，可在设置中启用级别虚线。跨芯片网络沿几何连通自动判断。

新GDS所有层默认不参与，不自动指定任何用途；checkbox可独立查看任意层，已保存工程恢复原设置。程序只读GDS；修复保留孔洞，不能恢复者用玫红细虚线标记并忽略。U为空间需求/可用空间的工程初筛，0%/100%是单个确定状态的违规标志；新增“预演分析”按来源固定RDL进行局部C1/C2连续型变，设置中选择贝塞尔或圆弧路径。只有通过最终布局校验的候选才显示；未通过则恢复原图，琥珀色叉号与“型变校验”表逐项说明原因。粉色DRC显示实际保留或型变后的图形问题。该预演不回写GDS，也不替代工厂完整DRC或量产良率证明。

8. “按芯片分别设置单边幅度”开启独立输入；右上“运行信息”显示时间戳输出和错误，完整日志写入 `logs/runtime.log`。预演分析会重复检查并适配新释放的窗口，粉色表示最终可见布局的规则违反。设置中可调最小铜内角，硬件检测通过后可选CUDA卷积加速；CPU始终可用。

具体预演使用最终布局二值判定；默认全局状态逐个迭代所有代表状态，并明确标出型变后连续概率未决项。有限代表状态不能证明连续6σ良率；复杂全图验证也不保证30 FPS。原GDS只读。

预演、概率、Space Map、具体状态及动画中间帧使用会话缓存。相同条件再次显示不重新求解；改变条件使用独立缓存，切回原条件可复用。设置可调“最大缓存个数 / 工程”（默认2000），按最近使用淘汰普通条目，无位移结果固定保留。工程之间切换保留缓存；主动点击“方案评估”清当前工程，关闭软件清全部会话缓存。清理菜单可清当前或所有已打开工程，旁边每0.5秒更新文件占用。达到数量上限、主动清理或重评估后的普通条目需要重新计算。绘制和可见性仍按当前窗口实时更新。

共用幅度框与逐芯片表都支持旋转中心：正中心、四角、自定义相对芯片中心X/Y（μm）。示例I覆盖独立旋转中心及芯片外扇出。所有变换、概率、Space Map、接触和型变共用该中心。

设置可调整接触空心圆与未适配叉号的颜色、直径及绝对大小。默认直径分别5 pt、7 pt；勾选绝对大小后按μm随图缩放。“显示良率级别范围”默认关闭；开启时使用0级全概率云，并叠加当前级别及可选多个级别的不同颜色虚线。虚线是包含整孔的保守扫掠包络，不是等概率线，最高受输入最大幅度限制。

“设置”可调整预演迭代、联合修复、孔盘级数/跨度、三段候选/最小长度/角部预留及单线程、多线程、spawn多进程；自动模式按CPU和内存限制并发，最终接受仍在主进程复核。几何布尔和DRC使用CPU；CUDA可用于概率卷积及符合条件的大型型变坐标批次。

“结果分析”以一张分组区间图显示连续安全范围：各DIE分列X/Y/O，右侧保留精确最小最大值；长度按各自输入单边幅度归一化，浅灰表示输入范围、三色表示安全范围，范围内所有组合对原始固定RDL异网均无接口接触。返回包含输入均值的较大体积已证内盒，不声明全局最大；均值已接触时不输出数值。范围独立于概率阈值，改变目标级别复用几何证书。详细范围/最优性限制见研究报告。

V20：不再采用新增孔盘包络或拼接新铜作为适配成功依据；实际铜轮廓由原材料位移产生，并核验原孔盘和连接弧的随动误差。反向路径复用验证帧；新路径仍需首算。完成状态与无位移结果保持缓存，高负载排队、资源允许时最多两项预演并行。

V21：新增示例M（不同芯片起始层及外部Pad）和N（三线路窄通道）。**宽度分析已重写**：删除原通道容量逻辑，改为逐个运动过孔的**落盘 air-gap** —— 过孔按 overlap 外扩作为落盘区，测量它到附近异网对象的最近距离，只在局部半径 R 内查找。**两种口径**（设置中切换）：*垂直方向固定RDL*＝到下方固定RDL层异网铜（短路风险）；*其他落盘区原始位置*＝到附近其他过孔**未偏移原位落盘**（侵占预留空间的风险，排除该孔自身原位落盘）。air-gap 小于有效线距判为不足、小于标注阈值判为临界，用 **CAD 式尺寸线＋数值**在图上标注并按严重度分色；动画中间帧按当前几何动态更新已定位风险，终态全量测量。落盘区、R、阈值与分析对象均可在设置中输入（overlap 默认0＝只用过孔本身，R 默认100 μm，阈值默认＝有效线距）。通过只代表 R 内的局部必要条件，不代表整图可布通、完整DRC或量产签认。原通道容量分析及其步进检查均已移除。详见本版说明。

新增 **修复补块**：按设备方“测偏移后用直线把固定RDL连到过孔新位置”的修复模型生成补块并显示；补块直径可在设置中输入，**默认与所连过孔等宽**（取过孔最小外接矩形的短边）。只有过孔与固定RDL失去接触时才补，然后对**补块后的图形**重做全局DRC，并把“补块新增”的违规与原有违规分开统计（按种类取并集做差，不计形状变化）。补块是简化模型，不替代工厂DRC或量产签认。口径见本版使用说明。

新增 **固定RDL重构预演**：产线不是让固定RDL保持不动——人工标出不能动的部分，其余按DIE的刚体变换移动以对回运动过孔，交界处裂开的缝用一块铜盖住。勾选 **重构预演** 后软件**自动猜**这条分界线：同一网络、彼此相距不远的多个落盘合成**一条串**，**整条串只切一刀**，切口**垂直于这条串的走线**（与走线两侧各成 **90°**，45° 走线得到 135° 切口），**位置由软件沿走线自动搜索**：从落盘边缘向外，止于同网络汇合节点或下一个同网络落盘，在**不与其它网络短路**的前提下取**横向最窄、附近最直**处（设置项 **D** 可写成固定距离，0＝自动；实在避不开时取间距最大处并把危险处标出来）；含整条串的一侧为移动区（同一图形的多条串取并集）。这样切口不会落在两个相邻落盘之间，也不会离自己的落盘特别远。移动区按该DIE的刚体变换（含旋转）移动；**同一块固定RDL横跨多颗芯片时，移动区只取本DIE芯片边框（`128/0`）以内的铜，边框外的铜留在原位归相邻DIE**（落盘例外，整个跟着走），因此各DIE的移动不会互相重叠；补线取**移动区切口面**与**不动铜切口面**的 **4 个端点**围成的多边形，把整条裂隙盖住，**不论裂隙大小（是否短路）都补**（只有两面完全重合或缝隙已被铜盖住时才不补），**补线外扩**可设置；裂隙、补线面积、切口缝长都列在表里；某图形整体成为移动区时标为 **整块随动（无不动铜可接）**；移动后两块铜相接、裂隙为 0 时标 **贴合（由补线覆盖）**——铜沿运动方向继续延伸时任何切线位置都拉不开这两块，这类缝本来就要靠补线盖住（实测 GD55 三芯片位姿 147 段里 66 段如此，把切口沿铜往外搜也只能拉开其中 3 段）。随后用**重构后的铜**替换名义图形，重跑“垂直方向固定RDL”的落盘 air-gap（只影响这一项，不重做DRC，“其他落盘区原始位置”口径不受影响）。暖色＝重构后的完整走线（固定区不动的铜＋移动后的铜＋补线，三段连成一条走线），冷色＝移动区原位，暗红虚线＝切口；表格逐段列出面积/位移/裂隙/补线面积/切口缝长/**间距**，点击可定位。切口位置也可以**在图上直接拖动**：拖动只让切口沿自己的法向平移（方向仍是与走线成 90° 的直线），松开就按新位置重算移动区、补线和间距检查，手动切口画成实线加粗、状态标 **手动切口**；右键/双击一条切口只清除那一条，**清除全部手动切口** 把所有串交还自动搜索；指针移到切口线上会亮起亮蓝色粗线提示可抓取，按下后真正拖动（≥3 像素）才会固定，松手只重算被改动的那一条串（GD55 单次拖动约 0.35 s）。每段重构后的走线都与**同层其它网络铜**量一次最小间距：小于有效线距标 **间距不足**、小于两倍标 **间距临界**，图上用比 air-gap 更大的字号画 `<->` 尺寸箭头并写出间距值。自动划分可能与人工划分不同，是预演而非产线做法，也不代表整图可布通或量产良率。示例F 中两颗DIE反向移动时，未重构看起来充足的 25 μm 间距，重构后暴露出 **0 μm 短路**；示例F 那段与相邻网络只剩 5.0 μm（线距 10 μm），表格标 **间距不足**、图上用尺寸箭头标出——位移本身把铜压过去了，换任何切口位置都避不开；GD55 实测三颗DIE分别偏移时整图 146 段、145 处补线、贴合 42 段、间距不足 44 段，移动区占 `5/0` 的 46.4%，各DIE的移动区互不重叠，每段切口都落在走线最窄处（实测多在 15–34 μm）。口径见本版使用说明。

**同一块固定RDL横跨多颗芯片**（GD55 实测）：移动区只取本DIE芯片边框（`128/0`）以内的铜，边框外的铜留在原位归相邻DIE（落盘除外），因此三颗DIE各走各的方向也不会把同一块铜挪两次；边框线本身也是一条切口，照样按 4 个端点补线。量裂隙时，已划给别的DIE、会跟着别的DIE走掉的铜不算“不动的铜”，所以反向移动不会被误判成撞在一起。
