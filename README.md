# Die Shift Analyze V12

GDS芯片偏移分析，长度单位为μm。本版修复小偏移与包围量的误拦截，增加三段连通追溯、独立DRC和鼠标偏移；支持逐芯片幅度、完整实体概率、运行日志、最新覆盖级别重算与迭代型变；按输入单边幅度生成极端组合，支持图形逐层点选/方向框选、实际红色侵入面积、可配置的整孔概率与整包 **Space Map**、插值运动及图形缓存。运动归属沿下层金属追溯，修复含重复边界、孔洞的GDS轮廓。

- [研究报告](DIE_SHIFT评估报告.md)
- [本版图文操作、公式与实图验证](docs/V12_操作与验证说明.md)

## 启动

```bash
python3 -m pip install -r requirements.txt
python3 main.py
```

Linux也可运行`bash run.sh`。Windows源码入口为`RUN.bat`；双击`BUILD_WINDOWS.bat`在Windows构建`dist/Die_Shift_Analyze.exe`并自动自检，构建后直接双击EXE。本次仅交付源码压缩包，不构建Linux冻结程序。Linux源码已验证；尚未执行Windows实机测试。

## 操作

1. 顶部Jobs工程下拉选择即打开；空白为新工程，新保存输入名称，已有工程直接覆盖。
2. “偏移”中打开GDS，指定边框及运动/固定RDL、运动/固定过孔。每层checkbox独立显隐，不参与层默认隐藏。从行内任意位置拖动调整上→下层序，最下金属应为接触芯片的层。
3. 芯片数量、尺寸、RDL层数、过孔几何自动读取。工艺分别设置运动/固定线宽线距；输入幅度为最大随机偏差；只通过目标覆盖下拉选择1–12或∞。有限k使用母标准差=B/k、在最大幅度盒内截断归一化的正态分布；∞或具体预演按当前几何二值判定。
4. 只有实际运动过孔—固定RDL接口参与不足及叠加；过孔—过孔仍可传递归属。无根/多根不能按最近芯片猜测，详见“信息”页的图层随动设置。
5. 评估后选择极端状态或手动指定DIE的DX/DY/O。标签页右侧的Space Map默认关闭，与运动概率独立。两圈虚线表示最小包围/再加线距，红圈与灰线定位其他网络接触，三个方案均以红色填充实际侵入面积，灰色虚线连接当前孔中心。极端组合按输入幅度生成，35 μm不会被置信半径放大为39 μm。
6. 边框不参与选择；左键单击逐层循环选中，空白单击或ESC取消；从左向右框选完全包含，从右向左框选所有相交图形。图片滚轮缩放、中键拖动；输入控件禁止滚轮改值。窗口改变时绘图区填满可用区域，保持X/Y等比例。目标覆盖级别变化会实时重算并更新显示，其他工艺输入保留既有报告直到再次评估。

7. 单击层/类型格子调整颜色和透明度。工艺右侧“设置”集中配置概率算法、精度及Space Map配色和平滑；可选确定性积分，无随机采样。示例D演示芯片外扇出，示例E演示连续型变、邻网限制和原图细颈，示例F演示逐芯片幅度及两轮释放窗口。Space Map可扩展至整个封装，非运动区域用基础线距。勾选插值运动后可设置时长上限、速度级别和FPS，默认时长上限1000 ms、30 FPS；预演速度和接触位置视角速度分别设置，实际计划时长随移动距离变化。结果分析上下两组图可拖动调整高度。

图片中按 **F** 恢复原视角，**M** 选择DIE后右键拖动、滚轮旋转，**ESC** 退出。表格和运行信息框支持滚轮上下滚动；数字/下拉值及层序仍禁止滚轮修改。“DRC问题”位于“叠加运动概率”左侧，可在未评估、未型变时独立检查。新增示例G展示小偏移孔盘适配及780 μm三段追溯。

旧晶圆/板段工程自动转换为运动/固定用途；保存的层序保持原样；新GDS按读取顺序列出，只有手动拖动改变层序。TEXT标签支持`PACKAGE_OUTLINE`、`DIE_OUTLINE`、`MOVING_RDL`、`FIXED_RDL`、`MOVING_VIA`、`FIXED_VIA`、`NON_METAL`、`KEEPOUT`及中文用途，旧标签继续兼容。

默认有限k按每接口接触概率p与2Φ(−k)比较；程序用概率上下界确认，无法决定者显示“概率待细化”，不把零采样命中当作通过。概率云显示整孔覆盖率，另用淡色虚线包络标示最大幅度内的可达极端。跨芯片网络沿几何连通自动判断。

程序只读GDS；修复保留孔洞，不能恢复者用玫红细虚线标记并忽略。Γ为保守工程初筛，0%/100%是单个确定状态的违规标志；新增“预演分析”按来源固定RDL进行局部C1/C2连续型变，设置中选择贝塞尔或圆弧路径。通过当前帧校验的候选与带DRC的最佳候选明确区分，拓扑非法或无候选时保留源图并列出原因。该预演不回写GDS，也不替代工厂完整DRC或量产良率证明。

8. “按芯片分别设置单边幅度”开启独立输入；右上“运行信息”显示时间戳输出和错误，完整日志写入 `logs/runtime.log`。预演分析会重复检查并适配新释放的窗口，粉色表示最终可见布局的规则违反。设置中可调最小铜内角，硬件检测通过后可选CUDA卷积加速；CPU始终可用。

具体预演使用最终布局二值判定；默认全局状态逐个迭代所有代表状态，并明确标出型变后连续概率未决项。有限代表状态不能证明连续6σ良率；复杂全图验证也不保证30 FPS。原GDS只读。
