# Die Shift Analyze V15

GDS芯片偏移分析，长度单位为μm。V15增加可配置迭代与三段通用截面、多进程候选搜索、可手算的空间比值U，以及每颗DIE的连续安全偏移范围。型变未通过最终约束时保留原图。

- [研究报告](DIE_SHIFT评估报告.md)
- [本版图文操作、公式与实图验证](docs/V15_操作与验证说明.md)

## 启动

```bash
python3 main.py
```

Linux可运行`bash run.sh`。Windows双击`RUN.bat`：使用已有Python环境，自动识别KLayout模块或已安装的桌面程序，**不联网、不创建空环境、不补装依赖**。可用`DIE_SHIFT_PYTHON`指定已有完整解释器；KLayout通常从PATH、环境变量、注册表或常用安装目录找到，也支持`DIE_SHIFT_KLAYOUT`指定exe路径。仅安装KLayout不能替代本应用的NumPy、Qt等依赖；已有环境不完整时会明确提示。

`TEST_WINDOWS.bat`检查默认与强制桌面后端。`BUILD_WINDOWS.bat`在已有完整PyInstaller环境中离线构建EXE，源包同时包含桌面调用宏。此次仅输出源码包；已验证Linux上的真实KLayout桌面进程，未执行Windows实机验证。

## 操作

1. 顶部Jobs工程下拉选择即打开；空白为新工程，新保存输入名称，已有工程直接覆盖。
2. “偏移”中打开GDS，指定边框及运动/固定RDL、运动/固定过孔。每层checkbox独立显隐，不参与层默认隐藏。从行内任意位置拖动调整上→下层序，最下金属应为接触芯片的层。
3. 芯片数量、尺寸、RDL层数、过孔几何自动读取。工艺分别设置运动/固定线宽线距；输入幅度为最大随机偏差；只通过目标覆盖下拉选择0–12或∞。非零有限k使用母标准差=B/k、在最大幅度盒内截断归一化的正态分布；0沿用最近有限非零级别（首次6）的概率尺度，不筛除边界内概率；∞或具体预演按当前几何二值判定。
4. 只有实际运动过孔—固定RDL接口参与不足及叠加；过孔—过孔仍可传递归属。无根/多根不能按最近芯片猜测，详见“信息”页的图层随动设置。
5. 评估后选择极端状态或手动指定DIE的DX/DY/O。标签页右侧的Space Map默认关闭，与运动概率独立。两圈虚线表示最小包围/再加线距，红圈与灰线定位其他网络接触，三个方案均以红色填充实际侵入面积，灰色虚线连接当前孔中心。极端组合按输入幅度生成，35 μm不会被置信半径放大为39 μm。
6. 边框不参与选择；左键单击逐层循环选中，空白单击或ESC取消；从左向右框选完全包含，从右向左框选所有相交图形。图片滚轮缩放、中键拖动；输入控件禁止滚轮改值。窗口改变时绘图区填满可用区域，保持X/Y等比例。目标覆盖级别变化会实时重算并更新显示，其他工艺输入保留既有报告直到再次评估。

7. 单击层/类型格子调整颜色和透明度。工艺右侧“设置”集中配置概率算法、精度及Space Map配色和平滑；可选确定性积分，无随机采样。示例D演示芯片外扇出，示例E演示连续型变、邻网限制和原图细颈，示例F演示逐芯片幅度及两轮释放窗口。Space Map可扩展至整个封装，非运动区域用基础线距。勾选插值运动后可设置时长上限、速度级别和FPS，默认时长上限1000 ms、30 FPS；预演速度和接触位置视角速度分别设置，实际计划时长随移动距离变化。结果分析中的方案比较、安全范围图和预演统计可拖动分隔条调整高度。

图片中按 **F** 恢复原视角，**M** 选择DIE后右键拖动、滚轮旋转、Ctrl+滚轮缩放，**ESC** 退出。表格和运行信息框支持滚轮上下滚动；数字/下拉值及层序仍禁止滚轮修改。“DRC问题”位于“叠加运动概率”左侧，可在未评估、未型变时独立检查。新增示例G展示小偏移孔盘适配及780 μm三段追溯。

旧晶圆/板段工程自动转换为运动/固定用途；保存的层序保持原样；新GDS按读取顺序列出，只有手动拖动改变层序。TEXT标签支持`PACKAGE_OUTLINE`、`DIE_OUTLINE`、`MOVING_RDL`、`FIXED_RDL`、`MOVING_VIA`、`FIXED_VIA`、`NON_METAL`、`KEEPOUT`及中文用途，旧标签继续兼容。

默认有限k按每接口接触概率p与2Φ(−k)比较；程序用概率上下界确认，无法决定者显示“概率待细化”，不把零采样命中当作通过。概率云显示整孔覆盖率，另用淡色虚线包络标示最大幅度内的可达极端。跨芯片网络沿几何连通自动判断。

程序只读GDS；修复保留孔洞，不能恢复者用玫红细虚线标记并忽略。U为空间需求/可用空间的工程初筛，0%/100%是单个确定状态的违规标志；新增“预演分析”按来源固定RDL进行局部C1/C2连续型变，设置中选择贝塞尔或圆弧路径。只有通过最终布局校验的候选才显示；未通过则恢复原图，琥珀色叉号与“型变校验”表逐项说明原因。粉色DRC显示实际保留或型变后的图形问题。该预演不回写GDS，也不替代工厂完整DRC或量产良率证明。

8. “按芯片分别设置单边幅度”开启独立输入；右上“运行信息”显示时间戳输出和错误，完整日志写入 `logs/runtime.log`。预演分析会重复检查并适配新释放的窗口，粉色表示最终可见布局的规则违反。设置中可调最小铜内角，硬件检测通过后可选CUDA卷积加速；CPU始终可用。

具体预演使用最终布局二值判定；默认全局状态逐个迭代所有代表状态，并明确标出型变后连续概率未决项。有限代表状态不能证明连续6σ良率；复杂全图验证也不保证30 FPS。原GDS只读。

预演、概率、Space Map、具体状态及动画中间帧使用会话缓存。相同条件再次显示不重新求解；改变条件使用独立缓存，切回原条件可复用。点击“方案评估”、更换GDS或关闭软件清理旧结果缓存。绘制和可见性仍按当前窗口实时更新。

共用幅度框与逐芯片表都支持旋转中心：正中心、四角、自定义相对芯片中心X/Y（μm）。示例I覆盖独立旋转中心及芯片外扇出。所有变换、概率、Space Map、接触和型变共用该中心。

设置可调整接触空心圆与未适配叉号的颜色、直径及绝对大小。默认直径分别5 pt、7 pt；勾选绝对大小后按μm随图缩放。“显示目标覆盖级别范围”默认关闭；开启时使用0级全概率云，并叠加当前级别及可选多个级别的不同颜色虚线。虚线是包含整孔的保守扫掠包络，不是等概率线，最高受输入最大幅度限制。

“设置”可调整预演迭代、联合修复、孔盘级数/跨度、三段候选/最小长度/角部预留及单线程、多线程、spawn多进程；自动模式按CPU和内存限制并发，最终接受仍在主进程复核。几何内核不支持通用显卡加速，CUDA仅用于支持的概率卷积。

“结果分析”以一张分组区间图显示连续安全范围：各DIE分列X/Y/O，右侧保留精确最小最大值；长度按各自输入单边幅度归一化，浅灰表示输入范围、三色表示安全范围，范围内所有组合对原始固定RDL异网均无接口接触。返回包含输入均值的较大体积已证内盒，不声明全局最大；均值已接触时不输出数值。范围独立于概率阈值，改变目标级别复用几何证书。详细范围/最优性限制见研究报告。
